# 추천 성분 모델 V4

`recommend-cat-v4`는 V3의 10개 입력에 피부 분석 v4.1의 트러블 점수 `acne_score`를 추가한 CatBoost 모델이다. 성분 정답 80개와 기존 학습·검증·테스트 분할을 유지하고, 학습 행에만 동일한 고정 설정으로 학습했다. `manifest.json`의 입력 순서와 모델 해시를 검증한다.

일반 피부 추천 API와 개발용 V1/V2 비교 API에서 `RECOMMENDATION_MODEL=recommend-cat-v4`로 선택한다. 요청에는 v4.1 분석 결과의 트러블 원점수가 필요하다. 기존 v4 분석 기록은 트러블 점수가 없어 다시 분석해야 한다. V3는 개발용 비교에서 이름을 `recommend-cat-v3`로 지정해 사용할 수 있다.

검증 792행에서 V3 대비 V4 P@5는 69.07%에서 69.47%, 테스트 792행에서는 67.83%에서 67.90%였다. 테스트 Top-5 macro-F1은 25.29%에서 25.22%로 낮아졌다. 단일 seed 및 이미 확인한 테스트셋의 성분 정답 일치도이며 실제 효능이나 사용자 만족도를 뜻하지 않는다.

트러블 모델에는 정상 피부가 학습·평가에 포함되지 않았고, 학습에 사용한 중안부 이미지와 앱 촬영 입력의 동등성은 검증되지 않았다. 원본 이미지·학습 행·개인 데이터는 번들에 포함하지 않는다.
