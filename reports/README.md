# 실험·평가 보고서

학습·실험·평가·모델 인계에 관한 Markdown 문서를 이 폴더에서 관리합니다.
협업 규칙은 루트 `CONTRIBUTING.md`·`AGENTS.md`, 앱 아키텍처는 `docs/ARCHITECTURE.md`에
유지합니다. 데이터·얼굴 이미지·가중치·개별 표본 결과는 이 폴더에 넣지 않습니다.

- [피부 분석 실험과 재현 절차](skin-analysis/README.md)

새 실험 분야가 생기면 `reports/<분야>/`에 문서를 추가합니다. 자동 생성된 상세 결과는
무시되는 `ml/runs/` 등 로컬 경로에 보관하고, 공유 가능한 집계 결과와 해석을 이곳에 기록합니다.
향후 LLM 서비스 호출 코드는 서버의 clients/services에, 별도 학습 코드는 필요할 때
`ml/src/`의 해당 영역에 둡니다. 보고서 폴더에 실행 코드를 섞지 않습니다.
