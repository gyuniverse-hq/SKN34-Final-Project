# 모공 SAM 조건의 WCE 상한 비교

실행 완료: 2026-10-24 22:36 KST
상태: 완료, valid 결과 비교

## 결론

SAM·제곱근 WCE에서 상한4와 무상한을 모공에 한해 비교했다. 두 seed의 Macro-F1 차이는 한 seed에서 상한4가 높고 다른 seed에서 무상한이 높았다. 평균은 상한4 **36.16%**, 무상한 **35.98%**로 0.18%p 차이다. 두 seed의 방향이 달라 **상한4가 더 낫다는 근거는 부족하다.** 고등급 정확 Recall 평균은 상한4 20%, 무상한 21%였다.

이번 결과에서 상한4는 필요한 설정으로 확인되지 않았다. 선정 규칙의 우선 지표가 Macro-F1이므로, 둘을 사실상 동률로 보고 추가 제한이 없는 무상한을 단순성 기준의 잠정 선택으로 둘 수 있다. 이는 무상한의 성능 우월성이 입증됐다는 뜻은 아니다. 기존에 인계한 상한4 모델의 가중치를 바꾸거나 서비스 모델을 교체한 것도 아니다.

## 비교 조건

| 고정 항목 | 설정 |
|---|---|
| 대상·분할 | 모공, 기존 train 690 / valid 138 인물. 기존 test는 사용하지 않음 |
| Backbone·초기화 | ResNet-50 ImageNet V2, 동일 사전학습 가중치 |
| 손실·최적화 | 제곱근 WCE (`α=0.5`) + SAM 기반 AdamW, `ρ=0.05` |
| batch | 실제·effective batch 모두 16 |
| 학습 | seed 17·42, head 2 + 전체 미세조정 18 epoch |
| 선택·평가 | valid Macro-F1 최대, 동률은 MAE 최소 후 이른 epoch. Macro-F1 우선 |
| 변경한 값 | 정규화 이후 클래스 가중치에 적용하는 상한: 4 대 없음 |

기존 상한4 실행은 오늘 대조의 seed17·42 결과를 사용했고, 무상한 실행은 같은 학습 코드와 데이터 fingerprint로 새로 수행했다. 두 조건의 데이터 fingerprint는 `6ac903796d100a2ee4f66e3e1936548dfa618c9b448a90985ff9ffbb0c13d793`, 학습 소스 fingerprint는 `fbb5e56c004bcba7cbc5f9dc12d88b4e5f61fadaf642875acc01305a7527fb7f`로 일치한다. 클래스별 차이는 모공 5등급 가중치 `4.0000` 대 `4.4941`뿐이다.

## 결과

평균 ± 표본 표준편차이며, 단위는 Macro-F1·Accuracy가 %, MAE가 등급이다. 고등급 정확 Recall은 4·5등급의 정확 등급 일치율이다.

seed별 Macro-F1에서 `상한4 - 무상한`은 seed17 **+0.78%p**, seed42 **-0.43%p**, 평균 **+0.18 ± 0.85%p**였다. 두 seed의 방향이 일치하지 않는다. 평균 표준편차와 두 seed만으로 신뢰구간이나 유의성을 주장하지 않는다.

## 해석과 선정 영향

상한4는 가장 희소한 모공 5등급의 가중치만 약 11% 낮췄다. Macro-F1 평균은 상한4가 0.18%p 높지만 seed 방향은 엇갈렸고, 고등급 정확 Recall 평균은 무상한이 1%p 높았다. Accuracy와 MAE의 seed 방향도 서로 달랐다. 현재 표본 수로는 상한의 명확한 성능 이득이나 일관된 보호 효과가 드러나지 않았다.

따라서 보고할 때는 다음처럼 설명한다. “제곱근 WCE와 SAM은 CE·AdamW 대조 결과를 근거로 우선 후보에 두었다. 상한4는 무상한과 비교했을 때 두 seed에서 차이 방향이 엇갈리고 평균 Macro-F1 차이가 0.18%p여서 필요한 설정이라고 입증되지 않았다. 설정을 단순하게 유지하기 위해 무상한을 잠정 사용하되, 이것이 우월하다는 주장은 하지 않는다.”

이 판단은 같은 기존 valid에서 두 seed를 비교한 결과다. 새로운 인물에 대한 검증은 아니며, 후속 인물 재분할 검증이 남아 있다.

## 기록 범위

이 보고서에는 상한4와 무상한의 설정, seed별 지표, 비교 해석을 기록했다. 개별 학습 로그와 원시 평가 JSON은 Git 보고서에 넣지 않고 로컬 `ml/runs/` 산출물로 보관한다. 이번 결과 보고서 묶음에는 실행 코드와 체크포인트를 포함하지 않는다.

seed17 학습은 20 epoch를 모두 완료해 checkpoint와 summary를 저장했다. 첫 실행에서 보조 스크립트가 완료 문구를 출력할 때 인자 위치 오류로 종료 코드를 실패로 반환했지만, 저장된 산출물을 확인하고 검증 평가를 다시 실행했다. 학습은 재시작하지 않았고 seed42는 수정된 스크립트로 정상 완료했다. 오류는 학습 결과 저장 후 발생했으며, 검증된 checkpoint 결과에는 영향을 주지 않았다.
