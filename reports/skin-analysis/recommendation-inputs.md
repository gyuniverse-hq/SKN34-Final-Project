# 피부 분석 결과의 추천 입력 선정

결정일: 2026-10-22. 사용자가 선택한 초기 범위와 수분 회귀값의 해석 근거를 기록합니다.
이 문서는 추천 설계이며, 추천 API나 화면에 연결이 완료됐다는 의미가 아닙니다.

## 선정 범위

| 항목 | 결정 | 추천 입력 |
|---|---|---|
| 여드름 | 유지 | 정상·여드름 이진 분류. 여드름성 패턴이면 진정 케어 제품을 우선하는 조건으로 사용 |
| 모공 | 유지 | 등급. 같은 항목의 회귀값은 추천에 중복 반영하지 않음 |
| 색소침착 | 유지 | 등급. 같은 항목의 회귀값은 추천에 중복 반영하지 않음 |
| 주름 | 유지 | 등급. 거칠기 회귀값은 추천에 중복 반영하지 않음 |
| 수분 | 추천에서 제외 | 예측 범위 압축과 저수분 구별 실패 확인. 분석 결과만 보관 |
| 탄력·처짐 | 추천에서 제외 | 분석 결과만 보관 |
| 건조 | 추천에서 제외 | 현재 입술 건조 모델이며, 얼굴 전체 건조 판정에 사용하지 않음 |

실패·미지원·누락 결과를 정상 또는 0으로 바꾸지 않습니다. 원본 분석 결과는 보존하고
추천에 전달하는 값만 선별합니다. 지표 선정은 해당 모델의 정확도 검증을 대신하지 않습니다.

선정 이후 [전체 성능 평가](full-performance-evaluation.md)를 진행했습니다. 스마트폰
모공·색소침착·주름은 최빈 정답 상수 비교보다 낮은 Accuracy와 낮은 Macro F1을 보였습니다.
여드름의 높은 점수도 합성 이미지에 한정됩니다. 따라서 이 표는 입력 계약의 선정 기록이며,
현재 등급으로 실제 추천 강도를 세분화할 품질이 검증됐다는 의미로 사용하지 않습니다.

2026-10-23에는 선별한 세 분류 모델을 스마트폰 데이터로 새로 학습했습니다.
[새 평가](smartphone-training.md)에서 기존 모델보다 Accuracy와 macro-F1이 개선됐지만,
모공 4·5등급 Recall은 0%이고 모공 5등급 평가 인물은 1명뿐입니다.
입력 네 항목의 선정은 유지하며, 제품 추천 강도의 근거로 등급을 확정하는 것은 별도 문제입니다.

네 항목만 실행하는 로컬 추론 모델 묶음과 기능 브랜치의 로딩 방법은
[모델 인계 문서](model-handoff.md)에 있습니다. 기존 `/dev/nia`는 전체 모델의
연구·비교 화면이며, 추천용 추론은 별도의 `RecommendationAnalyzer`를 사용합니다.

## 수분의 척도: 확인된 사실

- NIA 원본 로더는 `equipment`의 수분 측정값을 학습 정답으로 읽고, 학습 시 100으로
  나눕니다. 현재 `server/nia/engine.py`는 출력에 100을 곱해 원래 척도로 되돌립니다.
  따라서 화면 값에 다시 100을 곱하면 안 됩니다.
- 해당 데이터셋(71645)의 구축팀 논문 Methods 2.2.3은 이마·양쪽 볼·턱의 수분을
  **Corneometer CM825**로 측정했다고 명시합니다.
- 제조사는 Corneometer 값을 **장비 고유 임의 단위(arbitrary Corneometer units)**로
  설명합니다. `63`은 수분 63%나 100점 중 63점이라는 뜻이 아닙니다. 100은 학습용
  정규화 배율이지 측정값의 최대치가 아닙니다.
- 기존 로컬 설정의 단위 문자열은 여전히 `original label units (physical unit name
  unconfirmed)`입니다. 이번 조사는 외부 근거를 보완했으며 설정·추론 계약은 변경하지 않았습니다.

## 수분 구분: 검증할 후보

Roessle & Kerscher (2025)의 Methods에서는 같은 CM825의 **실측값**을 아래처럼 구분합니다.
이는 해당 연구가 사용한 기준이며, NIA가 공식 제공한 등급이나 현재 모델에서 검증된
추천 임계값이 아닙니다.

| 실측 CM 단위 | 해당 연구의 해석 |
|---|---|
| 30 미만 | 매우 건조 |
| 30~40 | 건조 |
| 40 초과 | 수분이 충분한 상태 |

이 경계를 추천에 채택하기 전 다음을 확인해야 합니다.

1. 현재 ResNet-50 체크포인트와 실제 전처리 조건에서 부위별 MAE·편향·저수분 표본의
   판별 성능을 평가합니다. 학습·검증·평가의 인물 중복도 함께 확인합니다.
2. 경계 근처의 예측 오차가 추천을 바꾸는 빈도를 평가하고, 검증 자료로 판단 보류 범위를
   정합니다. 오차 범위를 임의의 숫자로 정하지 않습니다.
3. 이마·양쪽 볼·턱 값을 보존하고, 얼굴 전체의 대표값이나 부위별 추천 정책을 따로
   검증합니다. 근거 없이 평균 또는 최솟값 하나로 합치지 않습니다.

구축팀의 2026 논문은 CoAtNet 모델의 결과를 보고합니다. 그 논문의 성능 수치를 현재
로컬 ResNet-50 체크포인트의 성능으로 대체하지 않습니다.

## 현재 체크포인트의 수분 범위 진단 (2026-10-22)

사용자가 실제 화면에서 예측이 50~65 부근에 몰린다고 관찰하여, 현재 체크포인트와
기존 NIA 전처리로 사용 가능한 스마트폰 평가 ROI 971개를 검사했습니다. 제공된
seed-1 테스트 ROI 1,070개 중 사용 가능한 부분집합이며, 자동 얼굴 영역 대신 원본
정답 bbox를 사용했습니다. 원본 데이터·분할·가중치는 변경하지 않았습니다.

| 지표 | 측정 결과 |
|---|---|
| 정답 수분값 범위 | 32.33~92.33 |
| 예측 수분값 범위 | 49.48~74.84 |
| 정답 / 예측 표준편차 | 10.16 / 3.77 |
| 예측이 50~65인 ROI | 727 / 971 (74.9%) |
| MAE / RMSE | 8.31 / 10.36 CM 단위 |
| Pearson r / R² | 0.144 / -0.039 |
| 정답이 40 이하인 ROI | 23개 |
| 해당 23개 중 예측이 40 이하인 ROI | 0개 |
| 해당 23개의 예측 범위 | 54.90~67.47 |

이 조건에서는 예측이 정답보다 좁은 범위에 몰리며, 문헌의 40 경계로 저수분 ROI를
구별하지 못했습니다. 50~65를 임의로 건조·보통·충분으로 다시 나누거나 min-max
변환해서 추천에 반영하지 않습니다. **수분은 추천 입력에서 보류**하고 분석값만
보관합니다. 원인이 가중치·학습·촬영 조건·전처리 중 무엇인지는 아직 확정하지 않았습니다.

평가 대상은 330명이며 제공된 **수분 항목**의 학습/검증 분할과 인물 교집합은 각각
328명/84명입니다. 이전의 0명 기록은 train/val의 `moisture` 키와 test의 부위별 키가
다른데 이를 동일하게 처리한 계산 오류였으며, 전체 모델 평가 준비 과정에서 정정했습니다.
같은 인물의 다른 부위/각도가 포함된 ROI 통계이므로 971명을 평가한
것은 아닙니다. 부분집합·통제된 스마트폰 촬영·체크포인트 전체 학습 이력 미확인의
한계가 있어 임의의 사용자 사진에 대한 일반화 성능으로 확대하지 않습니다.
상세 수치와 부위별 결과는 로컬
`nia-private/reports/moisture-range-diagnostic-20261022T120055Z.json`에 있습니다.
