# 오늘 마감용 WCE·SAM 근거 보강 계획

확정: 2026-10-24(KST). 사용자 마감: **오늘 23:30**.
학습은 **23:00**에 끝내고 보고서 정리에 30분을 확보한다.

## 목표와 바뀐 범위

**세 항목의 WCE와 SAM을 같은 배치에서 비교하고, 가중치 공식과 상한의 근거를 보강한다.**
기존 전체 연구는 일시 중단했다. 최고 모델의 광범위한 탐색 대신 오늘 완료 가능한
ResNet-50 내부 대조를 수행한다. 결과는 비교한 범위의 관찰과 잠정 후보로 기록한다.

| 구분 | 기존 전체 계획 | 오늘 계획 |
|---|---|---|
| 학습 수 | 최대 약 576회 | 최대 26회, 완료 2회 재사용 시 새 학습 24회 |
| 대상 | 모공·색소침착·주름 | 동일 |
| Backbone | 세 종류 | ResNet-50 고정 |
| 배치 | 16·32 | 실제/effective batch 16 고정 |
| 학습 seed | 탐색 3개, 확인 5개 | 17·42 두 개 |
| 손실 | CE·WCE·Focal·CB·CDF·CORAL | CE·제곱근 WCE·역빈도 WCE |
| SAM | 배치·가중치 교차 및 ρ 탐색 | 현재 제곱근 WCE에서 AdamW와 대조, ρ=0.05 고정 |
| 인물 재분할 | 개발 인물 3-fold | 오늘 생략, 기존 train/valid만 사용 |
| 기존 test | 마지막 감사 | 오늘 사용하지 않음 |
| 결론 | 항목별 최종 재선정 검증 | 항목별 관찰과 잠정 후보, 불일치는 선정 보류 |

## 우선 실행: 핵심 대조 18회

세 항목에서 다음 세 조건을 seed17·42로 반복한다.

| 조건 | 손실·최적화 | 확인할 질문 |
|---|---|---|
| CE | 일반 CE + AdamW | 가중치 없는 기준선 |
| 현재 WCE | 제곱근 역빈도·상한4 + AdamW | 현재 가중치가 CE보다 유리한가? |
| 현재 WCE+SAM | 같은 제곱근 역빈도·상한4 + SAM-AdamW | 배치를 바꾸지 않고 SAM을 추가하면 달라지는가? |

`3항목 × 3조건 × 2seed = 18회`다. 이미 완료한 모공 CE의 seed17·42를 검증 후
재사용하므로 핵심 대조의 새 학습은 16회다. 시작 순서는 모공 → 색소침착 → 주름이며,
각 항목에서 CE → 현재 WCE → 현재 WCE+SAM 순으로 seed 쌍을 완주한다.

## 남은 시간의 보강: 최대 8회

핵심 대조를 먼저 완료한 뒤 아래 순서로 실행한다. 결과가 좋아 보인다는 이유로
순서를 바꾸거나 후보를 추가하지 않는다.

| 순서 | 조건 | 추가 수 | 이유 |
|---|---|---:|---|
| 1 | 모공 제곱근 WCE·상한 없음 + AdamW | 2회 | 현재 상한4의 실제 효과 분리 |
| 2 | 모공 역빈도 WCE·상한4 + AdamW | 2회 | 제곱근과 더 강한 가중 방식 비교 |
| 3 | 색소침착 역빈도 WCE·상한4 + AdamW | 2회 | 해당 항목에서도 지수 효과 확인 |
| 4 | 주름 역빈도 WCE·상한4 + AdamW | 2회 | 해당 항목에서도 지수 효과 확인 |

모공만 상한 유무를 학습하는 이유는 [데이터 감사](02-preflight-data-audit.md)에서
제곱근 상한4가 모공 5등급에만 작동함을 확인했기 때문이다. 색소침착·주름의
상한4와 상한 없음은 같은 가중치여서 추가 학습하지 않는다.

지수는 CE=0, 제곱근=0.5, 역빈도=1이다. `(N/n_c)^α`를 학습 빈도 가중 평균이 1이
되도록 정규화하고 그 후 상한을 적용한다. 빈도는 train에서만 계산한다.

## 동일하게 유지할 조건

- 기존 인물 분할 train 690 / valid 138명, 데이터 fingerprint 유지.
- 정답 ROI 256px RGB·ImageNet 정규화·기존 약한 증강·반전 없음.
- ResNet-50 ImageNet V2, 실제/effective batch16, gradient accumulation 없음.
- seed17·42, seed·epoch·ROI별 고정 증강, 동일 shuffle 난수.
- head 2 + 미세조정 18 = 20 epoch 완주, 조기 종료 없음.
- valid Macro-F1 최대 → MAE 최소 → 이른 epoch로 checkpoint 선택.
- 기존 LR·cosine·weight decay·AMP·gradient clip·BN/overflow 복구 정책 유지.
- SAM의 두 forward에 동일 입력·난수 사용, ρ=0.05 유지.

20 epoch를 줄여 기존 결과와 다른 학습 예산을 섞는 방식은 사용하지 않는다.
오늘은 고정한 ResNet-50·배치16·기본 LR·ρ가 최적이라고 주장하지 않는다.

## 완료 결과의 재사용 조건

완료된 모공 CE 2회를 자동 재사용하기 전에 다음을 모두 확인한다.

1. 원래 학습 소스 snapshot과 현재 학습 파일이 바이트 수준에서 일치함.
2. worker의 AMP/TF32 설정과 학습 설정 해석 코드가 동일함.
3. 경로·실행기 해시 외의 전체 학습 설정과 데이터 fingerprint가 동일함.
4. PyTorch 등 저장된 패키지 버전과 가중치 SHA-256이 일치함.

실행기·보고서 변경과 실제 학습 계산 변경을 구분해 두 해시를 기록한다.
중단한 모공 CE seed73의 6 epoch 체크포인트도 보존하지만 오늘의 두 seed 비교에는 쓰지 않는다.

## 시간 관리

초기 추정은 새 학습 약 6~7시간이다. 조건별 실측이 쌓이면 같은 항목·optimizer의
전체 소요시간 중앙값으로 갱신한다. 시작 시간과 SAM 실측에 따라 보강 일부는 생략될 수 있다.

- 각 조건은 seed 두 개를 한 쌍으로 계획한다.
- 쌍의 미완료 실행 예상시간 합계에 15% 여유를 더해도 23:00 전에 끝날 때만 시작한다.
- 핵심 대조 미완료 상태에서는 보강을 시작하지 않는다.
- 실행이 23:00까지 끝나지 않으면 해당 실행기와 학습 자식 프로세스를 종료하고 체크포인트를 보존한다.
- 완료한 seed 쌍만 비교한다. 한 seed만 완료한 값은 상세 기록으로 보존하되 순위 계산에서 제외한다.
- 생략·실패·중단 이유를 보고서에 명시한다. 마감 때문에 조건을 임의 변경하지 않는다.
