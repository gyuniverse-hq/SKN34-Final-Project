# 실험 이력 보관

최종 사용 모델과 성능 판단은 [종합보고서](final-model-report.md)를 따른다.
실험별 Markdown·JSON·그림과 일회성 보고서 생성 스크립트는 통합 정리했다.

## 남긴 기록

- [근거 JSON](experiment-evidence.json)의 `reports`: 기존 집계 지표·혼동행렬·감사 결과 원문. 원래 파일명이 키다.
- `configs`: 학습 설정 TOML 원문. 실행 가능한 설정 파일도 ml/configs에 보존한다.
- `runs`: run별 선택 epoch·가중치 해시·학습 곡선 기록.
- `cleanup`: 삭제한 가중치의 SHA-256·크기·보호 대상 목록.
- 개별 얼굴 사진·인물별 예측은 공개 근거에 포함하지 않는다.

| 범위 | 수행한 비교 | 결정 |

## 재실험과 보존 기준

최종 모델 묶음과 현재 테스트 페이지가 참조하는 이전 가중치는 보호한다. 원본 데이터·
ROI 캐시·현재 서비스 설정은 변경하지 않는다. 그 외 실험 가중치·중간 optimizer
체크포인트·개별 예측은 제거한다. 따라서 과거 run을 그대로 재개하거나 과거
가중치로 재추론할 수는 없다. 재실험은 보존한 설정과 학습 코드로 새 output에서 시작한다.
원래 보고서 생성 스크립트는 Git 이력에서 복원할 수 있고 비교 조건 검사 함수는
`skin_analysis.smartphone.experiment_checks`에 남긴다. 기존 모델 파일을 전제하는
역사적 비교 CLI는 자산을 다시 학습/복원한 뒤 사용한다.
