# 피부 분석 모델 종합보고서 및 최종 인계

작성일: 2026-10-23. 최종 채택 방침은 모공·색소침착·주름에 **WCE + AdamW + SAM**을
사용하고 여드름은 기존 ImageNet 초기화 이진 분류 모델을 유지하는 것이다.
모든 가능한 알고리즘을 소진했다는 결론은 아니다. 현재 데이터·예산에서 수행한
실험을 종료하고 기능 제작에 사용할 연구용 모델을 고정하는 결정이다.

## 최종 평가 핵심

| 항목 | 기존 테스트 Acc / Macro-F1 | SAM 테스트 Acc / Macro-F1 | 해석 |
|---|---:|---:|---|
| 모공 | 55.56% / 30.08% | 61.54% / 31.01% | 전체 개선, 4·5등급 정확 등급 Recall은 1/48=2.08%에 불과 |
| 색소침착 | 52.11% / 42.21% | 52.76% / 40.20% | 정확도 +0.65%p, Macro-F1 -2.01%p; 일괄 개선 아님 |
| 주름 | 43.00% / 37.29% | 45.38% / 38.54% | 정확도 +2.38%p, Macro-F1 +1.24%p |

사용자 지정 방침에 따라 세 항목 SAM을 인계하되, 특히 색소침착의 테스트 고등급
Recall은 기존 25.40%에서 11.90%로 낮아졌다. 정밀한 고등급 구분이 필요한 용도에서
SAM이 항상 유리하다는 근거는 없다. 모공 5등급은 테스트에서도 0/6이다.
높은 ±1등급 정확도를 정확한 세부 등급 판정으로 설명하지 않는다.

선택 epoch/실행 epoch는 모공 9/15, 색소침착 7/13, 주름 9/15다.
테스트 결과를 본 뒤 체크포인트를 바꾸거나 추가 학습하지 않았다.

## 목적과 데이터

추천 입력은 여드름, 모공, 색소침착, 주름이다. 수분은 예측 범위 압축과 낮은
실측값 구분 실패로 제외했으며 탄력·처짐·입술 건조와 회귀 모델도 추천에 사용하지 않는다.
기존 NIA 제공 가중치의 학습 기기를 파일명만으로 스마트폰이라고 단정하지 않고,
스마트폰 Equ03 사진만으로 ImageNet ResNet-50에서 별도로 학습했다.

스마트폰 인물 965명을 train 690 / valid 138 / test 137로 고정 분리했다.
실제 분할은 7개 fold의 5/1/1이며 8:1:1이 아니다. 얼굴 사진 수, ROI 수, 독립 인물 수는
다르다. 같은 인물의 각도·부위는 같은 split에 묶는다. 데이터 fingerprint는
`6ac903796d100a2ee4f66e3e1936548dfa618c9b448a90985ff9ffbb0c13d793`이다.
평가는 정답 ROI의 정사각 JPEG 256px·RGB·ImageNet 정규화를 사용한다.
자동 셀카 ROI나 임의 촬영 환경에 대한 일반화 성능과 동일하지 않다.

## 수행한 실험과 해석

아래 개선 실험들은 **모공**에서 수행했다. 색소침착·주름에 Focal·CORAL 등을
전부 적용한 것은 아니며 이번에 WCE+SAM 학습을 확대했다.
아래 수치는 동일 모공 검증 138명·816 ROI의 6등급 결과다.

| 방법 | Accuracy | Macro-F1 | 판단 |
|---|---:|---:|---|
| WCE+AdamW 배치32 | 55.64% | 31.42% | 최초 스마트폰 기준선 |
| CB Focal 배치32 | 54.29% | 30.89% | 개선 없음 |
| CORAL | 52.94% | 24.86% | 선택 모델이 warmup 단계, 순서형 전체의 실패로 일반화 불가 |
| WCE+AdamW 배치16 | 54.41% | 33.29% | 배치 변경의 손익 확인 |
| BN 통계 고정 | 51.23% | 34.51% | 정확도 하락·학습/검증 격차 확대 |
| layer4만 미세조정 | 57.35% | 31.41% | 정확도 개선, Macro-F1 저하 |
| **WCE+AdamW+SAM** | **63.11%** | **36.34%** | 최종 모공 모델 |
| 순서형 CDF 손실+SAM | 62.99% | 35.68% | 거리 오차 개선, 4·5 정확 등급 Recall 2%로 하락 |
| Weighted Focal+SAM | 61.15% | 37.24% | F1 소폭 증가, 정확도·MAE 악화 |
| 특징 고정·균형 분류층 재학습 | 37.25% | 29.53% | 5등급 예측 44개 중 42개 오탐 |

WCE는 일반 CE에 학습 빈도의 역제곱근 기반 가중치를 부여하고 상한 4를 적용한
손실이다. AdamW는 최적화 알고리즘이며 SAM은 같은 배치의 두 gradient를 이용해
주변 손실까지 고려하는 학습 절차다. SAM은 손실함수나 새로운 backbone이 아니다.
선택 설정은 batch/effective batch 16, seed 42, rho 0.05, weight decay 0.0001,
warmup 2 + 미세조정 최대 18 epoch, patience 6, AMP다. warmup LR 0.001,
미세조정 head/backbone LR은 0.0001/0.00001이며 cosine 감소를 사용한다.
약한 회전·이동·색상 증강을 사용하고 좌우 ROI 의미 때문에 반전은 사용하지 않았다.

소량 균형 데이터 암기 검사는 100%에 도달했으나 일반화의 증거가 아니다.
모공 5등급은 학습 8명·48 ROI, 검증 1명·6 ROI로 특히 희소하다.
원본 라벨의 신뢰도를 보존하기 위해 외부 이미지의 자동 라벨 추가와 생성 이미지를
추가하지 않았다. 이 결과만으로 데이터셋의 오류나 라벨 품질 문제를 확정할 수 없다.

## 3단계 추천 구간 검토

모공 원본 예측을 `0·1 → 낮음`, `2·3 → 중간`, `4·5 → 높음`으로 매핑하는
방식은 검증 Accuracy 74.39%, Macro-F1 53.84%, 높음 Recall 20%였다.
처음부터 3출력을 WCE+SAM으로 학습하고 20 epoch를 완주한 결과는
74.14% / 51.74% / 16%였다. patience 6의 8 epoch 실행도 보존했으며,
20 epoch 실행의 처음 8 epoch 기록은 시간 외에 모두 일치했다.
따라서 모공은 6출력 가중치를 유지하고 필요할 때 최종 예측 등급만 묶는다.
확률을 쌍별 합산한 뒤 argmax하는 것은 다른 방식이며 높음 Recall 0%였다.

3단계 기준으로 수치가 높아졌다고 피부 판별 능력이 향상됐다는 뜻은 아니다.
3단계는 임시 추천 구간이며 임상 중증도나 물리적 측정 간격을 나타내지 않는다.
색소침착·주름의 세부 등급은 유지한다. 모공의 병합 기준을 다른 항목에 복사하지 않는다.

## 이번 확대 학습과 최종 평가 원칙

색소침착·주름은 모공과 같은 WCE+AdamW+SAM 배치16 설정으로 새로 학습했다.
기존 두 모델은 WCE+AdamW 배치32이므로 두 조건의 차이는 SAM과 배치 크기다.
이번 비교만으로 SAM 단독 효과를 분리했다고 주장하지 않는다.
모공은 기존 SAM 선택 가중치를 재사용하며 다시 학습하지 않았다.
각 run의 체크포인트는 검증 Macro-F1 최댓값, 동률이면 검증 CE로 선택한다.
사용 모델 방침은 테스트 평가 전에 고정했고 테스트 결과를 이용해 재학습하지 않는다.

분류 평가는 Accuracy, Macro/Weighted Precision·Recall·F1, 등급별 support·예측 수,
혼동행렬을 기록한다. 추가 해석 지표는 등급 MAE와 ±1등급 정확도다.
±1등급은 허용 오차 안에 든 비율이며 정확 등급 일치율과 구분한다.
회귀 모델은 사용 대상이 아니므로 이 최종 분류 평가에 회귀용 R²·MSE를 섞지 않는다.
이전 회귀 평가와 제외 근거는 [전체 평가](full-performance-evaluation.md)에 남긴다.
이번 train/valid/test 집계와 개별 등급 성능은 아래에 기록하며 부위별 평가는
동명 `.metrics.json`의 `areas`에 보존한다. 개별 인물 예측은 Git 제외다.

여드름은 이번에 재학습하지 않았다. 기존 합성 데이터 내부 test Macro-F1 1.0000,
ROC-AUC 1.0000, 공식 추가 감사 Macro-F1 0.9850은 과거 평가다.
이번 스마트폰 사람별 test와 다른 데이터이며 점수를 직접 합산하지 않는다.
실사 스마트폰 여드름 정확도·중증도 등급은 미검증이다.

## 인계와 남은 한계

최종 묶음은 `ml/runs/nia-smartphone-sam-seed-42/recommendation-bundle/`에 저장한다.
세 SAM 가중치와 기존 여드름 가중치, 해시·부위·등급 계약 manifest를 함께 전달한다.
Git에는 코드와 집계 보고서만 포함되므로 다른 브랜치·장비에는 묶음을 별도 복사해야 한다.
이 작업은 테스트 페이지 활성 설정이나 운영 API를 자동 변경하지 않는다.
추천 상품 로직과 Expo 기기 내 실행 형식 변환은 별도 작업이다.
얼굴 사진을 서버로 전송하는 운영 기능은 추가하지 않는다.

검증셋을 여러 실험에 반복 사용했고 일부 기준선 테스트는 이전에도 평가했다.
따라서 모든 수치를 새 외부 검증의 결과로 해석하지 않는다. 실제 서비스 판정에는
촬영 품질·자동 ROI·인물 다양성·소수 등급 재현율 검증이 남는다.
WCE+SAM 채택 방침과 각 항목에서 성능이 실제로 개선됐는지는 구분한다.
