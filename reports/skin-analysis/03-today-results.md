핵심 대조 18/18회, 전체 26/26회 완료. 기존 동일 조건에서 재사용한 실행 2회 포함.

학습 마감은 오늘 **23:00**, Markdown 보고 마감은 **23:30(KST)**이다. 마감에 맞지 않는 보강은 생략하고 생략 이유를 기록한다.

## 질문과 비교 조건

현재 WCE가 일반 CE보다 유리한지, 같은 배치에서 SAM을 추가하면 무엇이 달라지는지 확인한다. 여유 시간에는 역빈도와 모공 상한 유무를 비교한다.

| 고정 조건 | 설정 |
|---|---|
| 학습 | ResNet-50 ImageNet V2, batch/effective batch 16, seed 17·42 |
| 예산·선택 | head 2 + 미세조정 18 epoch 완주, valid Macro-F1 → MAE → 이른 epoch |
| 입력·증강·LR·AMP·BN | 기존 전체 계획과 동일, ROI·epoch별 고정 증강 |
| 기존 test | 학습·선정·이번 평가에 사용하지 않음 |

## 결과와 같은 seed 대조

성능은 평균 ± 표본 표준편차다. MAE는 등급 단위다. 고등급 정확 Recall은 모공·색소침착 4·5, 주름 5·6의 정확 등급 일치율이다.

## 한계와 선정 영향

이번 결과는 비교한 ResNet-50 학습법의 잠정 근거다. seed 두 번과 같은 valid의 반복 사용만으로 일반화나 통계적 우월성을 입증하지 않는다. 관찰이 seed마다 엇갈리면 선정 보류로 기록한다.

다른 backbone·배치·Focal·CORAL·CDF·인물 재분할·ρ 탐색은 오늘 수행하지 않는다. 따라서 해당 기법보다 낫거나 현재 설정이 최적이라는 결론은 내리지 않는다.
