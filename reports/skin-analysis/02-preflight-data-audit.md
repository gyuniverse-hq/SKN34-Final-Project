# 학습 전 데이터·가중치 감사

확인일: 2026-10-24(KST). 학습 결과를 사용하지 않은 원본 분할 감사다.

## 핵심 결론

**WCE는 기본 CE가 아니다. 학습 빈도에서 계산한 별도 가중치를 사용한다.**
현재 제곱근 가중치의 상한 4는 모공 5등급에서만 작동한다. 색소침착·주름에서
상한 4와 상한 없음은 같은 가중치이므로 A단계에서 중복 학습하지 않는다.

역빈도 가중치는 희소 등급의 상대적 영향이 크고 제곱근은 더 완만하다. 이는 수식의
성질이며, 제곱근이나 상한 4가 실제 성능에 유리하다는 증거는 아니다. A단계에서 검증한다.

## 실험에 반영한 사항

- 모든 가중치는 각 실제 학습 분할에서 다시 계산한다. valid·바깥 평가·기존 test 빈도를 사용하지 않는다.
- A의 중복 제거는 현재 학습 분포에서 벡터가 정확히 같은 경우에만 적용한다.
- D에서는 고정한 대표 설정의 지수·상한을 유지하되 새 학습 빈도로 다시 계산한다.
- 모공 5등급의 기존 valid·test 인물이 적어 단일 등급 Recall을 안정적 일반화 성능으로 확대하지 않는다.
