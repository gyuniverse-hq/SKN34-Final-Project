# 아이섀도우 호수별 마감 검수 자료 (2026-11-18)

올리브영 원본 아이섀도우(팔레트 상품 제외) 1,079개 옵션의 마감을 사람이 검수한 결과다.
판정 기준은 AR 담당이 정한 아이섀도우 마감 6종 기준표(펄 유무·광택·펄 크기)다.
브랜드가 "글리터"라고 표기했더라도 입자가 쉬머로 보이면 쉬머로 판정했다.

| 파일 | 내용 |
| --- | --- |
| `option_finishes.csv` | 옵션별 마감 코드, 판정 방식, 판정 근거, 검수 시각(KST) |

| 코드 | 의미 | 옵션 수 |
| --- | --- | ---: |
| `matte` | 매트 | 406 |
| `satin` | 새틴 | 156 |
| `shimmer` | 쉬머 | 327 |
| `metallic` | 메탈릭 | 7 |
| `glitter` | 글리터 | 69 |
| `glossy` | 글로시 | 10 |
| `accessory` | 소도구 (공용기·브러쉬·케이스) | 16 |
| `palette` | 옵션 하나에 여러 색 | 57 |
| `other_category` | 립·쿠션·블러셔 등 다른 카테고리, 아이 베이스 | 29 |
| `unknown` | 판정 불가 | 2 |

판정 방식(`judge_step`)은 `manual_image`(이미지 보고 개별 판정) 984개,
`manual_bulk`(한 라인 전체를 같은 마감으로 판정) 95개다.

마이그레이션 `0026`이 마감 코드표 `raw_oy_finish_type`과 판정 테이블
`raw_oy_option_finish`를 만든다. `load_eyeshadow_finish.py`는 기본 실행 시
읽기 전용 사전 검사를 하고 `--apply`에서 이 CSV를 `raw_oy_option_finish`에 넣는다.
같은 옵션·검수 시각의 행은 건너뛰므로 다시 실행해도 중복되지 않는다.
앱 서빙 테이블(`products`/`shades`)은 이 단계에서 바꾸지 않는다.
