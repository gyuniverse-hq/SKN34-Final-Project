# MagicMakeup vs Stable-Makeup: 비교 프로토콜 (생성 결과 없음)

조사일: 2026-11-20. 모든 측정칸은 **미측정**. 빈 생성 이미지를 만들지 않는다.

## 목적

같은 소스·참조로 두 모델과 현재 VISHUE AR, 실제 발색을 나란히 본다. 앱에 모델을 넣지 않는다.

## 공정 조건

- 제품: 전후 파일이 확인되기 전 **미확정**. 스펙 후보는 힌스 무드인핸서 립 글로우이나 확정하지 않음.
- 5칸: 맨얼굴, 실제 발색, VISHUE AR, MagicMakeup, Stable-Makeup. 자료가 있는 칸만.
- 실제 발색을 생성 참조로 넣고 같은 사진을 정답 CIEDE2000에 쓰지 않음. 분리 불가면 한계를 표에 적음.
- 사용자 맨얼굴 셀카는 바른 뒤가 없어 이 실험의 정답이 아님.

|---|---|---|---|---|---|---|

논문 표의 DINO-I·CLIP-I·Face-ID·L2M·FID는 **저자 벤치 숫자**이며 우리 실험과 칸을 나눈다. 한 장 FID는 쓰지 않는다.

## 적용 가능성 (가설)

- MagicMakeup: 부위 마스크와 비편집 영역 오차로 번짐을 본다. UV에 생성 텍스처를 펴는 것은 정면 1장만으로는 측면·입 벌림에 **불가**로 표시.
- Stable-Makeup: 립 색 분포·하이라이트는 셰이더 참고 후보. 자동 매핑은 미검증.
- 직접 합치지 않음.

## 선행 조건

`env_check.md`: 이 PC에 CUDA GPU 없음. 가중치 미다운로드. GPU·라이선스·공개 샘플 1쌍이 있을 때 Stable-Makeup부터 돌린다.
