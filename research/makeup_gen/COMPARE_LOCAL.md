**지표**
- **입술 ΔE00:** 입술 마스크(MediaPipe 478점) 안 CIELAB 중앙값으로 계산한다. 사람이 구분할 수 있는 최소 차이는 약 2.3이다.
- **입술 밖:** 입술 주변 21px를 뺀 얼굴 영역이다.
- **주름 상관·세기:** 맨입술 대비 L* 주름 대역(G2−G6)을 비교한다. 광택 점은 빼고 계산한다(`texture_metric.py`). 세기가 1이면 맨입술과 같고, 1보다 크면 주름이 진해진 것이다.

**해상도**
- C는 1024에서 쟀다.
- D·F와 그 후처리는 512에서 쟀다. 1024로 키우면 F + 색 차이만이 0.86, D + 색 차이만이 2.86이다.
- AR은 자기 프레임(720×960)에서 쟀다.

**처리 시간**
- FPMT는 실행마다 3.1~4.1 s였다(두 번 실행, 각 9회 중앙값).
- 후처리 시간은 재지 않았다(CPU, 수 초 이내).

그림: `research/data/makeup_gen/eval/fig_compare_all.png`(git 제외). 입술 확대 10칸이다(윗줄 A·B·B′·B″·C, 아랫줄 D·D+색·F·F+색·E).

## 2. 해석

1. **AR의 가장 큰 오차는 입력 색이다.**
   - 같은 셰이더에서 공식몰 광고색(#C77276)을 실제 발색(#A26263)으로 바꾸면 8.01이 2.97(glossy)이나 1.13(matte)이 된다.
   - 생성 모델 셋 중 FPMT를 뺀 둘(MagicMakeup 3.50, Stable-Makeup 2.70)보다 "실측 색을 넣은 AR"이 정확하다.
2. **FPMT가 레퍼런스의 입술색을 가장 정확하게 옮긴다(0.5~0.7).**
   - 단, 레퍼런스가 정답 사진 E 자체라 **순환**이다. 이 값은 "옮기는 정확도"이지 "다른 사람 사진으로 내 발색을 예측하는 정확도"가 아니다.
3. **얼굴 전체가 바뀌는 문제는 후처리로 해결된다.** 생성 모델 셋은 모두 입술 밖이 바뀐다(2.4~6.4). 입술만 합성하면 0이 된다.
   - **색 차이만:** 맨입술 모양과 결을 그대로 둔다(IoU 0.97~0.98, 주름 상관 0.998).
   - **잘라 붙이기:** 출력의 입술 모양을 따라가므로 경계가 보일 수 있다.
4. **결(질감)**
   - AR은 결을 지우지 않는다(세기 1.1~1.4).
   - glossy는 광택 점(5~7%)을 더하고, 진하기를 올릴수록 원래 주름과의 상관이 떨어진다(0.92 → 0.79).
   - matte는 주름을 1.44배 진하게 해서, 그림에서 입술이 회색빛으로 말라 보인다.
   - E의 주름 세기는 1.65배다. 다른 촬영이라 비교는 참고만 한다.
5. **속도:** 실시간에 쓸 수 있는 것은 AR뿐이다. FPMT는 생성 모델 중 가장 가볍지만 노트북 CPU로 장당 3~4초다.

## 3. 앱 적용 가능성

| | VISHUE AR | MagicMakeup | Stable-Makeup | FPMT |
|---|---|---|---|---|
| 제품 hex 입력 | 가능 | 불가 | 불가 | 불가 |
| 부위별 조절(10개 부위, 진하기·모양) | 가능 | eyes / lip / 전체 3가지 | 불가(얼굴 전체) | 불가(얼굴 전체) |
| Expo Go 안에서 실행 | 가능(WebView + WebGL) | 불가(VRAM 33GB) | 불가(VRAM 10GB) | 어려움(얼굴 분할 모델 동반, 웹 런타임 변환 필요, 폰 속도 미확인) |
| 얼굴 영상 서버 전송 | 없음 | 서버 GPU 필요 | 서버 GPU 필요 | PC·서버에서 실행 |
| 라이선스 | 자체 | 비상업(FLUX dev) | Apache-2.0 | 비상업(CC BY-NC-SA 4.0) |

결론: 앱 안의 실시간 렌더는 AR을 유지한다. 생성 모델(특히 FPMT)은 앱 밖에서 **AR에 넣을 색과 진하기를 정하는 오프라인 도구** 후보로만 쓴다.

## 4. 한계

- 1명, 1제품, 사진 1쌍이다. 모델별 seed는 C·D만 3개이고 F는 결정적이라 1회다.
- E는 레퍼런스이면서 정답이다(순환). AR 보정색 #A26263도 E에서 뽑았다.
- A와 E는 조명·시점·안경이 다르다. E와의 ΔE에는 촬영 차이가 섞여 있다(A와 E의 차이 3.94 중 일부).
- 순환을 끊으려면 **다른 사람이 같은 제품을 바른 얼굴 사진**이 레퍼런스로 필요하다. 공식몰 COLOR CHART는 입술만 잘린 사진이라 FPMT 입력(얼굴 정렬 + 분할)으로 쓸 수 없다.
- 광택 점 기준(+8 L*)과 주름 대역(G2−G6)은 이번에 정한 값이다.
