# LaPa 입술 모델 비교 — 10장 예비 결과

2026-11-09 사용자 RunPod 실행 결과를 로컬 CSV와 summary로 대조했다. 여섯 결과의 사진 ID 10개가 모두 같다. 파일명순 앞 10장이며 동일 인물일 가능성이 있는 사진이 포함되어 대표 표본이 아니다. LaPa test 정답 마스크의 윗·아랫입술을 합쳐 비교했다. 기록된 GPU는 RTX 4090이다. 정확도는 이미지별 값의 중앙값이다.

| 방식 | 입술 IoU 중앙값 | 예측 중 정답 밖 비율 중앙값 | 정답 중 누락 비율 중앙값 | 비고 |
|---|---:|---:|---:|---|
| FaRL LaPa | 0.844 | 7.3% | 8.2% | 축소 전 검출 결과. LaPa 학습 버전 |
| FaRL CelebM | 0.675 | 17.5% | 19.3% | 640px 축소 얼굴 검출, 다중 얼굴 1장 |
| MediaPipe 윤곽 | 0.668 | 16.7% | 18.2% | 정지 사진의 앱 입술 다각형 근사 |
| BiSeNet R18 | 0.667 | 24.2% | 13.3% | ONNX Runtime CUDA, 일부 CPU 노드 |
| SegFormer | 0.630 | 20.3% | 14.6% | 얼굴 사진 전체 입력 |
| MediaPipe 힌트 + SAM 2.1 large | 0.347 | 63.9% | 0.0% | 모델이 스스로 점수를 매긴 마스크 중 최고점 선택 |

넘침은 `(예측 − 정답) / 예측`, 누락은 `(정답 − 예측) / 정답`이다. 예측 면적이 0인 경우 넘침은 정의되지 않으며 중앙값에서 제외한다. 중앙값을 각각 계산하므로 행 내 지표로 IoU를 역산할 수 없다. SAM 2의 낮은 누락은 정확한 경계를 뜻하지 않으며, 높은 넘침과 함께 해석한다.

## 해석과 제한

- FaRL LaPa는 LaPa를 학습에 사용한 버전으로, 다른 데이터에서 학습한 후보에 비해 같은 출처의 test 분할에서 유리할 수 있다. 시험 분할은 학습용 분할과 구분하되, 이 결과만으로 일반화 성능을 확정하지 않는다.
- 원본 FaRL LaPa와 FaRL CelebM은 얼굴 검출 입력 크기가 다르다. 화면에서 확인된 축소 후 FaRL LaPa IoU 0.837의 CSV는 이 폴더에 없어 표에 넣지 않았다. 모델 자체 비교는 검출 조건을 같게 맞춰 재실행해야 한다.
- FaRL CelebM에서 한 이미지 IoU가 0이다. 얼굴은 검출됐으며, 같은 실행에 다중 얼굴 1장이 기록돼 있다. 잘못된 얼굴 선택 또는 분할 실패 여부는 이미지와 예측을 직접 확인하기 전까지 미확인이다. BiSeNet도 IoU 0.040과 0.161인 사진이 있다.
- SAM 2는 손으로 준 정답이 아닌 MediaPipe 점에서 힌트를 만든 합성 파이프라인이다. 제시한 박스·점의 영향과 이중 입술의 객체 분할 문제 때문에 다른 힌트 방식의 SAM 2 성능을 대표하지 않는다.
- 사진·정답이 같은 10장이어도 얼굴 검출, 입력 크기, 전처리, 얼굴 선택, 추론 방식이 다르다. 입술 정답의 품질, 학습 데이터 중복, 인물 단위 독립성 및 소표본을 감안한다. 정확도와 립스틱 발색·결·광택의 재현은 별개다.

## 속도 기록

현재 CSV 중앙값은 SegFormer 모델 forward 38.89ms, BiSeNet ONNX `session.run` 7.61ms, MediaPipe CPU 랜드마커 20.13ms, SAM 2 이미지 설정+마스크 예측 85.83ms(별도 MediaPipe 22.78ms)다. FaRL의 저장된 측정은 검출 약 25초와 분할 약 27~38ms로 나뉜다. 초기 실행·워밍업을 포함한다. 모델마다 전후처리·전송·검출 포함 범위가 달라 위 숫자를 통합 FPS나 모델 간 공정한 속도 순위로 비교할 수 없다. 사용자 실기기 속도가 아니며 처리 구간별 반복 측정이 필요하다.
