# 립 AR 교사 평가 예비 결과 — 2026-11-13

**판정: 사람 검수를 돕는 보조 채점. 검수 없는 대량 학습 라벨 생성은 보류.**

R1·R4·R5의 원본으로 기준을 재집계했다. R2·R3 제외는 사용자가 선택한 평가자 범위이며, 두 평가자의 답변이 잘못됐다고 검증한 결과는 아니다. R5 파일의 R0 코드는 파생 데이터에서만 R5로 정정했다. 원본은 변경하지 않았다.

설명용 34장(17명)을 전체·확대 사진 및 3명 답변과 함께 확인한 뒤, 얼굴이 겹치지 않는 시험용 16장(8명)을 채점했다. 시험용에는 임의 별칭과 제형만 제시하고 사람 점수·종류 표시는 가렸다. 시험 16장의 25개 체크(총400개)와 전체 인상, 관찰 근거를 모두 저장·잠근 후 정답을 비교했다. 시험 결과를 보고 답변을 수정하지 않았다. 판단불가는0개였다.

체크82.75%는 3명의 대표 답변과 비교한 값이다. 85.81%와84.10%는 한 사람을 제외한 두 사람이 같은 예/아니오에 동의하는 동일한 사례에서 교사와 제외된 사람을 비교한 값이다. 항목별 일치율의 평균이며 NA는 별도 분석했다. 이 두 종류의 비율은 분모가 다르다. 비교 시행896개는 독립 이미지896장이 아니라 같은16장을 반복 집계한 값이다. 교사−사람 차이의 얼굴 단위95% CI는 -3.62~+11.74%p로, 교사가 사람보다 우수하다고 결론 내릴 수 없다.

점수의 신뢰구간은 얼굴 단위로2,000회 재표집했다. 렌더끼리 순위 상관의 신뢰구간이0을 포함하므로 사전에 정한 다음 단계 적격 조건을 충족하지 못했다. 스티커·렌더·실제의 평균 순서는0.60 < 3.08 < 4.40이고, 세 종류 조합의66.7%가 그 순서를 충족했다. 쉬운 극단을 구별한 것과 렌더의 미세 차이를 구별한 것을 분리해 읽어야 한다.

총점이 같아도 라벨이 같지는 않았다. T02는 사람·교사 총점이 모두4.40이지만 체크5개에서 대표 답변이 달랐다. 같은 얼굴 렌더끼리의 순서는6쌍 중3쌍만 사람 평균점수와 같았다. 이6쌍은 다른 색·제형이며 사람 점수 차이가0.067~0.633점으로 작다. 직접 사람 A/B 선호 실험이나 렌더 버전 비교 정확도로 해석하지 않는다.

**기록할 한계와 교정 사항**

- 이번 결과는 현재 Codex 대화에서 문맥 내 예시를 참고한 시각 평가이다. 모델 가중치를 학습하지 않았으며 별도 API 모델을 실행하지 않았다. 정확한 API 모델 snapshot과 디코딩 설정은 이 실행에서 확보하지 못했다.
- 전체 입력은720×960, 입술 확대는512×512였다. 시각 평가에서는 전체를360×480로 표시하고 확대 이미지는512×512로 유지했다. 확대 이미지 자체가 저해상도 원본에서 만들어진 경우 새로운 세부정보가 생기지 않는다.
- 맨입술 원본이 없어 실제 결 보존량을 직접 검증하지 못한다. 여기서 q1_2는 기존 평가 화면과 동일하게 결과에 보이는 결로 판단했다. 실물 발색 정확도·동영상 추적 안정성은 평가하지 않았다.
- 기존 시험 세트는 앞선 Qwen 실험에서 이미 사용됐다. 본 교사에게 이미지별 정답은 숨겼지만 이전 전체 요약은 대화에 있었다. 새로운 독립 검증 세트를 대신하지 않는다.
- 사람3명은 팀원이다. 모집단 전체의 절대 정답으로 볼 수 없고, 사람마다 답변이 갈리는 체크를 대표 답변 하나로 확정하면 불확실성이 사라진다.
- 사후 감사에서 설명용 사진 P19·P21·P28의 윤기(Q3) 표시 평균이 잘못된 것을 발견했다. 일부 평가자만 NA를 고른 항목에서 전체 유효표를 합산한 비율을 표시했기 때문이다. 표시값0.333/0.778/0.667은 평가자별 점수를 먼저 계산한 평균0.200/0.667/0.500으로 정정해야 한다. 설명용 총점과 시험 정답·교사 총점 계산은 모두 맞았다. 사용한 원래 화면은 보존하고 별도 교정 자료를 만들었다. 교정본은 이번 시험에 사용하지 않았으며 다음 독립 검증부터 사용한다. 시험 정답을 이미 공개했으므로 재채점으로 덮어쓰지 않고 새 검증의 한계로 기록한다.

다음 권고는 결·경계·제형 조건의 해석을 사람과 맞춘 뒤 새로운 얼굴로 재시험하는 것이다. 대량 라벨 생성이나 sVLM 학습은 시작하지 않았다. 현재 점수는 검수 보조 및 오류 분석용이며 학습 정답으로 자동 승인되지 않는다.
