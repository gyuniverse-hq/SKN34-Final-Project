# 숙제 01 촬영 체크리스트: 맨입술 / 실제로 바른 입술

> **대상:** 촬영에 참여하는 팀원(모델과 촬영자)
> **목적:** 같은 사람, 같은 조명, 같은 카메라 위치에서 **맨입술**과 **실제로 바른 입술**을 찍는다. 그 사진으로 AR 결과가 "실제로 바른 모습"에 얼마나 가까운지를 눈대중이 아니라 숫자(ΔE2000, 밝기 분포, 결 SSIM)로 판정한다.
> **규칙 원문:** `docs/AR_SPEC.md` 8-A-1 (이 문서는 그 체크리스트판). 비교 도구: `research/lip_reference/hw01_compare.py`
> **소요:** 한 사람 × 한 조명 × 제품 3개 기준 약 40분

---

## 1. 꼭 지킬 것 (하나라도 빠지면 그 세트는 비교에 못 씀)

- [ ] **카메라를 삼각대나 고정대에 고정**한다. 맨입술 → 1번 → 3번을 찍는 동안 **카메라·의자·조명을 움직이지 않는다.** 위치가 바뀌면 같은 픽셀끼리 비교할 수 없다.
- [ ] **노출·화이트밸런스를 고정**한다(프로 모드, 자동 끄기). 고정이 안 되는 기종이면 `meta.csv`의 `fixedExposure`를 `no`로 적는다.
- [ ] 같은 조명 조건 안에서는 장소·조명 기구를 바꾸지 않고 `setupId`를 하나로 적는다.
- [ ] 보정·뷰티 필터를 끈다(기본 카메라 앱의 뷰티 모드 포함). 편집한 사진은 쓰지 않는다.
- [ ] 동의서를 받은 팀원만 찍는다. 사진은 `research/data/`에만 두고 **채팅·드라이브·PR·문서에 올리지 않는다**(AR_SPEC 1-4, 1-13).

## 2. 준비

- [ ] 팀원 **3명 이상**, 피부톤·성별이 다르게
- [ ] 제품 **3개 이상**, 가능하면 **매트·새틴·글로시가 각각 하나** (힌스 무드인핸서 립 글로우부터 시작해도 됨)
- [ ] 클렌징 티슈·립 리무버 (제품 사이에 완전히 지우고 맨입술부터 다시 찍음)
- [ ] 삼각대, 휴대폰 1대 (기종 기록)
- [ ] 조명 두 가지: **주광(창가, `day`)**, **실내 노란 조명(`warm`)**. 한 가지만 가능하면 `day`부터
- [ ] (있으면) 컬러카드. 얼굴 옆, 턱 높이에 두고 모든 사진에 같이 나오게 한다. 없으면 생략한다(색 실측은 보류된 상태)

## 3. 촬영 순서 (제품 하나당)

1. [ ] 입술을 깨끗이 지운다. 립밤도 바르지 않는다.
2. [ ] 정면을 본다. 입은 **편하게 다문 상태**. 표정은 무표정.
3. [ ] **맨입술 `_0`** 을 정면(`00`), 30°(`30`), 45°(`45`)로 찍는다. 각도는 얼굴을 돌리고 카메라는 그대로 둔다.
4. [ ] 제품을 **1번** 바른다. 입술선 밖으로 나가지 않게 바르고, 손가락으로 펴지 않는다.
5. [ ] **1번 `_1`** 을 같은 세 각도로 찍는다.
6. [ ] 2번 더 덧발라 **3번 `_3`** 을 같은 세 각도로 찍는다.
7. [ ] 지우고 다음 제품으로 간다(1번부터 반복).

- 정면 사진에서 입술 가로가 **화면 짧은 변의 1/4 이상**이 되게 거리를 잡는다(대략 40~50cm).
- 각 단계에서 **2장씩** 찍어 두고 흔들린 것은 지운다.

## 4. 파일 이름과 저장 위치

```text
research/data/hw01_raw/{사람}_{조명}_{각도}_{제품}_{횟수}.jpg
  사람: p1, p2, ...        조명: day | warm       각도: 00 | 30 | 45
  제품: 소문자-하이픈 (예: hince-dearrose)       횟수: 0(맨입술) | 1 | 3
  예: p1_day_00_hince-dearrose_0.jpg   ← 맨입술 (그 제품을 바르기 직전)
      p1_day_00_hince-dearrose_1.jpg   ← 1번 바름
      p1_day_00_hince-dearrose_3.jpg   ← 3번 바름
research/data/hw01_raw/meta.csv
research/data/hw01_masks/{같은 이름}.png   ← 정면 정답 마스크(선택, 입술 = 흰색)
```

같은 장에 2장 이상 남기면 끝에 `-b`를 붙인다(`..._1-b.jpg`). 비교 도구는 `-b`가 없는 파일을 쓴다.

이름 검사: `python research/protocol/check_names.py` → 규칙에 안 맞는 파일, 짝(맨입술 `_0`)이 없는 바른 사진, `meta.csv`에 없는 제품을 목록으로 보여 준다.

### `meta.csv` (제품 하나에 한 줄)

| 열 | 설명 | 예 |
|---|---|---|
| `product` | 파일 이름의 제품 부분과 똑같이 | `hince-dearrose` |
| `hex` | 앱에 들어 있는 그 셰이드의 hex (AR 렌더에 씀) | `#B5655F` |
| `texture` | 앱 제형 이름: matte, velvet, cream, satin, sheer, glossy, shimmer | `glossy` |
| `device` | 기종 | `galaxy-s24` |
| `setupId` | 조명 조건 이름 | `room1-day` |
| `fixedExposure` | 노출·WB 고정 여부 | `yes` |
| `takenAt` | 날짜 | `2026-10-28` |
| `note` | 메모(피부 상태, 입술 각질 등) | |

## 5. 정답 마스크 (선택이지만 있으면 정확해짐)

- 정면 `_1` 사진마다 입술(윗입술 + 아랫입술, 입 안쪽 제외)을 흰색, 나머지를 검은색으로 칠한 PNG. 도구는 무료 이미지 편집기면 된다.
- 마스크가 없으면 비교 도구가 MediaPipe 얼굴 점으로 입술 영역을 대신 잡는다. 이 경우 입술 경계 근처는 비교에서 빠진다(안쪽만 비교).

## 6. 하지 않는 것

- 공식몰·판매 사이트·SNS 사진을 "실제로 바른 사진"으로 쓰기 (조건이 달라 비교가 안 됨)
- 사람마다 카메라 위치를 바꾸며 찍은 사진을 맨입술과 짝짓기
- 흰 종이를 얼굴 옆에 대기 (8-A-1. 화이트밸런스는 고정으로 해결)
