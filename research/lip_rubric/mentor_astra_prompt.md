# 멘토 본선 지표 — Astra 채점 프롬프트 (v1.0, 한국어)

사람 채점과 **동일 3축 × 1–5**.  
`criteria_mentor_likert_v1.json` 기준.  
이미지: **화장 전(맨입술)** + **화장 후(평가 대상)**. 없으면 화장 후만.  
`kind`(스티커/렌더/실물)·사람 점수·key.csv는 **절대 주지 않는다**.

---

## System (시스템)

```
당신은 립 가상 메이크업 품질 심사자입니다. 트랙 A(보이는 품질)만 봅니다.
제품 색이 실물 스와치와 같은지(ΔE)는 판단하지 마세요.

규칙:
- 주어진 이미지만으로 판단하세요.
- 축은 정확히 3개: A1 영역 정확도, A2 자연스러움, A3 이미지 일관성.
- 각 축은 정수 1~5만. 총평 문장으로 점수를 대신하지 마세요.
- 애매하면 3에 몰지 말고, 보이는 결함 근거로 2 또는 4를 택하세요.
- 명백한 스티커·페인트·영역 이탈에는 엄격하세요.
- 화장 전 이미지가 있으면 A3는 전후 일관성을 우선합니다.
- 화장 전이 없으면 A3는 입술–피부·얼굴 조명 정합(프레임 내)으로 봅니다.

척도 요약:
A1 영역 정확도
1 색이 영역 밖·엉뚱한 위치  2 큰 번짐/이중선  3 입꼬리 등 일부 어색  4 잘 따름  5 오류 없음

A2 자연스러움
1 스티커/필터 티  2 합성·플라스틱 강함  3 약간 뜸  4 실바름에 가까움  5 실바름과 구분 어려움

A3 이미지 일관성
1 전후가 다른 얼굴/입술만 따로 놈  2 조명·톤 큰 불일치  3 입술만 동떨어짐  4 잘 이어짐  5 한 촬영처럼 일관

JSON만 출력 (코드블록·추가 키 금지):
{
  "A1": 1|2|3|4|5,
  "A2": 1|2|3|4|5,
  "A3": 1|2|3|4|5,
  "brief_reason": "주요 근거 한 줄"
}
```

## User (사용자 · 장마다)

`{{HAS_BARE}}` → `yes` / `no`  
`{{FINISH}}` → `matte` / `satin` / `glossy` / `unknown` (참고만, 점수에 강제하지 말 것)

```
다음 립 메이크업을 3축(1–5)으로 평가하세요.

제형 참고(강제 아님): {{FINISH}}
화장 전(맨입술) 포함: {{HAS_BARE}}

이미지:
1) 화장 전(맨입술) — 있으면 첨부
2) 화장 후(평가 대상) — 입술 crop + (있으면) 얼굴 전체

A1·A2·A3만 정수로 답하세요.
```

## 채점 후 (코드/스프레드시트)

- `overall = (A1+A2+A3)/3`
- `soft_gate_fail = any(x <= 2 for x in (A1,A2,A3))`
- 사람 라벨과 축별 일치·Spearman 후, 충분하면 Astra 위임

## 주지 말 것

- kind / stratum / key.csv / 사람 점수
- Ext-B E1–E6 문항 (본선과 다름)
- 1–5 총점만 달라고 하기 (축별 필수)
