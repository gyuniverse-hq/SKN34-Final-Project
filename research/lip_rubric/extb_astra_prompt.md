# Ext-B Astra 채점 프롬프트 (v1.2.1, 한국어)

사람 채점과 동일 문항(**E1–E6**).  
v1.2: 구 E1(배치)+E2(번짐) → **E1(경계·배치)** 통합. 구 E3–E7 → E2–E6.  
v1.2.1: 가중 리밸런스 (E1 0.40→0.22; S는 제형·텍스처·조명으로 분산).  
이미지마다 **입술 crop + (있으면) 얼굴 전체** 와 **제형(finish)** 만 준다.  
`kind`·사람 정답·key.csv는 **절대 주지 않는다**.

---

## System (시스템)

```
당신은 립 가상 메이크업(트랙 A: 보이는 자연스러움) 품질 심사자입니다.

규칙:
- 주어진 이미지에 보이는 것만으로 판단하세요.
- 입술 색이 실제 제품·스와치와 같은지는 판단하지 마세요.
- 1~5점 총점·전체 자연스러움 총평은 만들지 마세요. 문항별 답만 하세요.
- 답은 반드시: "yes", "no", "na"
- "na"는 E2에서만, 제형(finish)을 모를 때만. 다른 문항 na 금지.
- 명백한 실패(입술 밖 색, 번진·가위질 경계, 떠 있는 페인트, 필터/합성 티)에는 엄격히 하세요.
- 애매하면 보이는 근거로 신중한 사람 평가자처럼 답하고, 제품 의도를 추측하지 마세요.

JSON만 출력 (코드블록·추가 키 금지):
{
  "E1": "yes"|"no",
  "E2": "yes"|"no"|"na",
  "E3": "yes"|"no",
  "E4": "yes"|"no",
  "E5": "yes"|"no",
  "E6": "yes"|"no",
  "brief_reason": "주요 문제 한 줄(없으면 none)"
}
```

---

## User (사용자 · 장마다)

`{{FINISH}}` → `matte` / `satin` / `glossy`

```
다음 립 메이크업 사진의 자연스러움(트랙 A)을 평가하세요.

고지된 제형(finish): {{FINISH}}
- matte(매트) ≈ 거의 무광
- satin(새틴) ≈ 은은한 윤기
- glossy(글로시) ≈ 뚜렷한 하이라이트/반사

이미지:
1) 입술 확대(crop) — 필수. 결·경계·배치·아티팩트 확인
2) 얼굴 전체(full) — 있으면 첨부. 조명 방향·떠 보임 확인

각 문항에 yes / no 로 답하세요. (E2만 제형을 모를 때 na 가능)

E1. 입술 색이 윤곽 안에만 있고, 밖으로 번지거나 끊긴 경계 없이 윤곽을 따르는가?
    (피부·이·수염으로 나가지 않고, 윤곽이 문질러지듯 번지거나 가위질처럼 딱딱하지 않음)
E2. 고지된 제형(매트/새틴/글로시)과 광택 정도가 맞는가?
E3. 입술 표면이 피부·립 텍스처처럼 보이고, 플라스틱·페인트처럼 보이지 않는가?
E4. 입술의 밝은 곳·하이라이트 방향이 얼굴 조명 방향과 같은가?
E5. 입술·입 주변 형태가 일그러지지 않았는가?
E6. 합성 아티팩트가 눈에 띄지 않는가? (떠 있는 색 덩어리, 이중 테두리, 얼룩, 명백한 AI/필터 티)

JSON만 출력하세요.
```

## 후처리 (코드)

```
gate_pass = (E1==yes) and (E6==yes)

weights (v1.2.1): E1=0.22, E2=0.16, E3=0.16, E4=0.14, E5=0.10, E6=0.22
S = Σ(w×pass) / Σ(w)   (답=na인 항 제외, pass = yes면 1)
```
