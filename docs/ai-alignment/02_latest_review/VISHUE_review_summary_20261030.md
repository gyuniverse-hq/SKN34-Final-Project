### 사례별 상세 작업·팀 질문

#### E-AR-02 · AR
- **문제:** 선택 상품·호수가 없고 layers={}인 A2에서 강도 변경 대상이 없음. 기본 립 레이어를 허용할지 미정.
- **추천 해결:** (A) 편집 가능한 립 레이어 없음: 명령 0개·립/제품 선택 안내. (B) 기본 레이어 있음: 실제 상품·호수 및 지원 명령 계약 확인 후 강도 제안. 제품↔호수 연결 원칙 위반 금지.
- **담당자에게 확인할 결정:** 선택 상품 없이 기본 립 레이어 허용 여부, layerExists·productId·shadeId 불변조건, supportedActions 확인
- **필요한 fixture/테스트:** A2a: layers={}, selectedProductId=null, shadeId=null, expected=CLARIFICATION/no-op. A2b: 실제 편집 가능한 립 레이어 존재(유효 상품/호수 또는 합의된 예외) 별도 테스트
- **완료 기준:** 미존재/존재 분기별 fixture 2개+명령 생성 여부+AR 상태 무변경/제안 검증; 상품·호수 관계 검증
- **기준 데이터:** D01/D07/D08/D09; **검수 상태:** 팀/데이터 확인 대기. 정책 확정·코드 수정·Gold 승인 미수행.

#### E-AR-14 · AR
- **문제:** 현재 상태·성공 이력 불일치. Undo는 제안 로그가 아닌 실제 ACK 성공 이력을 기준으로 해야 함.

- **담당자에게 확인할 결정:** Undo 대상(AI만/수동 포함), ACK 후 스냅샷 시점, Undo의 Undo, 동시 적용·중복 방지, 상태버전 증가
