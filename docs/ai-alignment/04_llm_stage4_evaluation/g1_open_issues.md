# G1 #244 병합 전 핵심 항목과 병합 후 평가

기준: 2026-11-16. 기능·평가 기준선은 `b08ac900aaeeec56db8a43c097b5f2204e69d72a`. GEN-06·07, CAT-02의 코드 수정은 `3a78cd2`에 반영됐다. 아래 기준선 수치를 수정 코드의 실제 판정으로 사용하지 않는다.

## 결정된 진행 방식

#244의 목표는 핵심 결함 수정과 최소 검증을 거쳐 안전하게 코드 병합을 판단하는 것이다. 기존 47개 사례·70개 predicate·113개 필수 실행 계약과 실행 증빙은 유지한다. 전체 평가 완료와 사람 평가 18건은 병합 후 별도 완료 게이트로 관리한다. #244는 담당 리뷰와 병합 판단 전까지 Draft, `G1_SUPERVISOR_ENABLED` 기본 OFF다. 코드 병합은 G1 전체 검증 완료나 플래그 기본 활성화를 뜻하지 않는다.

[Issue #247](https://github.com/gyuniverse-hq/SKN34-Final-Project/issues/247)의 네 가지 정책 방향은 유지한다. REG-02·REG-07·GEN-11의 평가 원본 개정은 담당 검토와 별도 승인 뒤 진행하고 현재 FAIL/BLOCKED/NOT_RUN을 PASS로 바꾸지 않는다.

## 병합 후 이관하며 현재 상태를 유지할 항목

기준선 113건: E0 31 PASS/1 FAIL/13 NOT_RUN, E1 17 PASS/1 BLOCKED_DATA, E2 3 PASS, E3 12 PASS/19 NOT_RUN, E5 13 PASS/3 NOT_RUN. 합계 **76 PASS / 1 FAIL / 1 BLOCKED / 35 NOT_RUN**. 사람 평가 18건은 모두 미판정. 기존 증빙은 저장소 밖 `g1-final-b08ac90`에 보존한다. 새 코드의 실행 결과로 복사하지 않는다.

- E0/E1/E2/E3/E5 필수 113건 전체의 미완료 관측, 실제 오류, 데이터 의존성을 사례·변형·환경별로 해결한다.
- 실제 E3 응답 18건의 사람 의미 판정을 검토자가 수행한다. GEN-11 정형 응답의 모델 span 조건은 계약 개정과 별도 증빙이 필요하다.
- REG-02 상대 AR 확인 질문/절대값 제안, REG-07 원본 상품·보강 이미지 출처, GEN-11 정형 안전 응답의 평가 기준을 담당 승인 후 정식 개정한다.
- Expo 웹 E5와 Android/iOS E6 실기기, 팀 전체 E2E를 구분해 완료한다. 최종 clean HEAD에서 113건을 다시 판정한다.

이 이관은 평가 결과 면제나 G1 완료 선언이 아니다. 평가 원본 및 이전 실행 기록을 삭제하거나 완화하지 않는다.

## #246 통합 위험

[PR #246](https://github.com/gyuniverse-hq/SKN34-Final-Project/pull/246)은 AR 제어·음성 기능이며 현재 별도 `develop` 대상 PR이다. #244와 겹치는 `backend/chatbot/app/services/chat_service.py`, `app/clients/llm_client.py`, `app/core/config.py`, `pyproject.toml`, `uv.lock`, `tests/test_chat_sessions.py`는 충돌 가능 파일이다. #244의 최소 수정에서 `llm_client.py`도 변경되므로 통합 때 특히 확인한다. #244에 #246의 AR 기능을 임의로 가져오지 않는다. #244 병합 뒤 #246을 최신 `develop`에 통합하는 순서를 우선 검토하고, 실제 base·diff·회귀를 다시 확인한다.

현재 코드 병합 판단에는 이 문서의 분리된 게이트를 적용한다. 과거 전체 평가 선행 기준은 기존 PR 본문 이력으로 보존한다.
