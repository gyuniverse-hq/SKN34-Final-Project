# 검색 화면의 제품 표시 기준

검색 화면과 색조·기초 탭은 기존 `GET /api/products`의 카탈로그를 읽는다. 제품은 검색 결과와 제품 둘러보기에서 볼 수 있으며 상세 화면으로 이동한다. 실시간 검색어와 별점·리뷰 수를 제공하는 계약은 없으므로 수치를 표시하지 않는다. 최근 검색은 기기에만 저장되며 개별 삭제할 수 있다.

`Product.tags`에 아래 태그가 명시된 경우에만 해당 영역에 표시한다. 이는 운영자가 입력한 카탈로그 값이며 자동 집계한 실시간 순위가 아니다. 실제 선정 기준과 태그 갱신은 데이터 운영자가 관리한다.

- `rank:makeup:1`, `rank:makeup:2` 등: 색조 랭킹. 색조 범위는 `lip`, `cheek`, `eye`, `base`다.
- `rank:skincare:1`, `rank:skincare:2` 등: 기초 랭킹. 기초 범위는 `skincare`, `suncare`다.
- `bestseller`: 인기 제품 영역에 노출할 제품.
- `new`: 신상품 영역에 노출할 제품. 날짜가 아니라 운영자 지정 태그이므로 더 이상 신상품이 아니면 제거한다.

순위 번호는 1~9999 정수다. 카테고리와 맞지 않는 태그, 한 제품에 같은 종류의 순위가 두 개 이상인 경우, 동일 탭에서 중복된 순위 번호는 순위 표시에서 제외한다. 순위가 없는 제품도 해당 탭의 별도 제품 목록에서 볼 수 있다. 순위·태그가 없는 DB 데이터만 적재되어도 검색과 제품 목록은 동작하지만 랭킹, 인기·신상품 영역은 자동으로 채워지지 않는다.
