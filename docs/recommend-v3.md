# recommend-v3 개발 이력

`recommend-v3`는 **AR 추천과 피부 분석 추천을 묶는 릴리스 이름**이다. 피부 추천은 V1에서 성분 기반
기준선을 만들고 V2에서 성분 예측과 리뷰 보정을 실험했다. AR 추천은 시착과 장바구니 이력을 팔레트 순위에
반영하는 방향으로 발전했다.

## V1 피부 고민과 성분을 연결하다

사용자가 고른 주·보조 고민을 검수된 성분 매핑과 연결해 상품 후보를 만들었다. 제조사의 피부 타입·민감성 표기를
조건에 맞춰 반영하고, 리뷰는 소표본을 완화하는 보조 점수로 사용했다. 후속 규칙에서는 리뷰 수 중앙값인 207개를
설문 응답 반영 강도의 기준으로 사용했다. 이 작업으로 고민별 추천 근거를 설명하고 같은 상품 데이터에서 순위를
비교할 수 있는 기준선이 생겼다. [V1 동작과 추적](skincare-recommendations.md#v1-동작과-추적) ·
[후속 규칙의 설문 보정](skincare-recommendations.md#v2-입력과-목록-구성)

## V2 성분 예측과 리뷰 신뢰도를 실험하다

CatBoost로 고민에 맞는 핵심 성분을 예측한 뒤, CosIng 기능을 통해 성분 후보를 확장하고 제품에 연결했다.
V1과 V2의 순위를 같은 상품 스냅샷에서 비교하는 도구와 요청·후보·실제 노출·사용자 반응 이력도 마련했다.
[V2 비교 설계와 실험](recommendation-v2-comparison.md) · [V2 이력 설계](recommendation-v2-feedback-erd.md)

고정 보정값을 데이터에서 추정하는 방식으로 발전시켰다. 상품 940개의 별점 분포로 경험적 베이즈 사전 강도
`K≈34.87`과 평균 `μ≈4.80`을 추정했다. 리뷰 수로 평점 추정의 불확실성을 반영하고, 피부 타입별 리뷰 응답으로
상품의 적합도를 보정하는 방법도 검증했다. V2에서 `recommend-cat-v3`는 이 성분 예측 모델의 버전명이었다.
[V2 리뷰 보정](recommendation-v2-comparison.md#리뷰-및-최종-목록) ·
[성분 모델 적용 기록](recommendation-v3-handoff.md)

## V3의 피부 분석 추천

추천 결과를 성분 매핑으로 설명하고 모델 운영 부담을 줄이기 위해 V1의 규칙 기반 추천을 바탕으로 삼았다.
모공·톤잡티·주름·트러블의 연속 점수가 모두 있는 프로필은 네 항목을 모두 반영한다. 유의 경계를 크게 넘고 다른
항목보다 두드러지는 고민에 추가 가중치를 준다. 검증된 CosIng 기능 충족도와 이미 선정한 상품이 보완한 고민을 함께 봐 종합 TOP 10을
구성한다. [종합 추천 규칙](skincare-recommendations.md#v4-종합-추천-2026-11-09)

성분 적합도와 피부 조건이 같은 후보는 V2에서 얻은 경험적 베이즈 보정 별점, 리뷰 수에 따른 신뢰도, 피부 타입의
리뷰 응답 적합도로 재정렬한다. 예를 들어 같은 성분 적합도의 건성 후보에서 4.6점·리뷰 1,000개·건성 응답 75%인
상품이 5.0점·리뷰 2개인 상품보다 앞서는지 테스트했다. [리뷰 정렬 규칙](skincare-recommendations.md#v4-리뷰-정렬-2026-11-20) ·
[건성 순위 테스트](../backend/api/tests/test_skincare_profile_balance.py)

## V3의 AR 추천

직접 탐색의 첫 팔레트는 리뷰 수로 보정한 제품 평점에서 시작한다. 같은 부위의 최근 90일 시착·담기 기록이 쌓이면
선호하는 색과 제형을 반영한다. 추천 후보와 노출·시착·담기 이력을 연결하면서, 실제 반응으로 CatBoost 후보를
학습하고 운영 기준선과 A/B 비교할 수 있는 경로를 마련했다. 모델 적용은 AR의 실험 설정과 평가 결과에 따른다.
[AR 팔레트 추천과 실험](ar-recommendation-mlops-v1.0.md#1-서비스-범위와-현재-상태)

## V3 평가

- **피부 분석 추천**은 실제 노출 세션을 기준으로 담기율, 노출 100세션당 담긴 추천 상품 수, 담기에서 결제로
  이어진 비율을 집계한다. 담기와 확인된 결제 사이의 연결은 피부 추천 전용 테이블에 저장된다. 운영 집계는 앱·API 배포와
  `0028` 마이그레이션 적용 뒤 수집에 동의한 회원의 노출부터 시작한다.
  [피부 추천 집계 방법](recommendation-v2-feedback-erd.md#집계-실행)
- **AR 추천**은 추천 칩의 노출에서 시착·담기와 확인된 결제까지 추적한다. 모델 도입 실험의 주요 지표는
  관찰을 마친 전체 추천 세션 대비 구매율이다. [AR 구매 전환 지표](ar-recommendation-mlops-v1.0.md#51-추천칩-노출부터-앱-내-구매까지의-전환-지표)

공통 주문 기록에서 결제를 확인하고, 각 추천의 노출·담기 이력과 정책 버전에 구매를 연결한다.

## V1·V2 실행 경로 종료

피부 리포트는 `/api/recommendations/skincare/v4`와 그 이력 API를 사용한다. 이전 `/skincare`, `/skincare/v2`,
`/skin-v2`와 V1·V2 개발 비교 경로는 종료했다. 해당 API를 호출하는 앱은 V3 API 배포 시 업데이트가 필요하다.
과거 실험의 실행 코드는 Git의 `ffad408`에서 확인할 수 있다. [V1·V2 비교 기록](recommendation-v2-comparison.md)
