# AI-Hub Data Rights and Storage Decision

AI-Hub 「문제성 피부 메이크업 추천 데이터」(datasetSn 71961)의 보관 위치와 이용 범위
결정입니다. `VISHUE_AIHUB_DB_Handoff_20261102` 요청서의 **0단계 산출물**입니다.

- 결정일: 2026-11-03
- 결정 주체: 데이터 담당
- 상태: 1·2단계 착수 가능. 공용 DB 적재는 보류

## 1. 결정

**AI-Hub 원본과 그 발췌는 공용 DB(Supabase)에 올리지 않습니다. 원본은 각자 국내
로컬 환경에만 둡니다.**

## 2. 근거

공용 Supabase 프로젝트의 리전은 `ap-northeast-1`(도쿄)입니다. 도쿄 리전에 업로드하면
데이터가 국외 서버에 저장되므로 국외 반출에 해당합니다. AI-Hub 이용정책에 다음 조항이
있습니다.

> "본 AI데이터 등의 국외 반출을 위해서는 수행기관 등 및 한국지능정보사회진흥원과
> **별도로 합의가 필요합니다.**"

> "국외에 소재하는 법인, 단체 또는 개인이 AI데이터 등을 이용하기 위해서는 수행기관 등
> 및 한국지능정보사회진흥원과 별도로 합의가 필요합니다."

금지가 아니라 사전 합의 요건이며, 현재 그 합의가 없습니다.

"해외에서의 다운로드 금지"는 접속 지점에 관한 별개 조항이며 국외 저장을 허용하지
않습니다. 작업자가 모두 국내에 있고 데이터를 외부에 공개하지 않는다는 사실은 저장
위치 요건을 충족시키지 못합니다.

출처: [AI-Hub 이용정책](https://aihub.or.kr/intrcn/guid/usagepolicy.do)

## 3. 보관 위치와 접근 주체

| 대상 | 위치 | 공유 |
| --- | --- | --- |
| 원본 ZIP, 압축 해제본 | 각 담당자의 국내 로컬 환경 | **공유하지 않음.** 각자 본인 AI-Hub 계정으로 내려받음 |
| 로컬 DB `aihub` 스키마 | 각 담당자의 로컬 PostgreSQL | 공유하지 않음. 같은 스크립트로 각자 생성 |
| 스키마 SQL, 적재·검증 스크립트 | 저장소 | Git |
| 필드 사전, 고민 13종·피부 4종 코드표 | 저장소 | Git |
| 검증 결과 집계(건수·분포·실패 유형) | 저장소 | Git |
| 원문 인용, 발췌, DOC 본문, 임베딩 | 어디에도 올리지 않음 | — |

팀원 간에 원본을 전달하지 않습니다. 이용정책에 "제공 받은 AI데이터 등을 승인을 받지
않은 다른 법인, 단체 또는 개인에게 열람하게 하거나 제공, 양도, 대여, 판매하여서는
안됩니다" 라는 조항이 있어, 각자 본인 계정으로 내려받는 편이 안전합니다.

**데이터를 공유하지 않고 절차를 공유합니다.** 저장소의 스키마와 적재 스크립트가 있으면
각자 원본을 받아 같은 명령으로 같은 로컬 DB를 만들 수 있습니다. 올리브영 수집본을
서로 주고받지 않고 각자 적재하는 방식과 같습니다.

## 4. 착수 가능 여부

| 범위 | 가능 여부 |
| --- | --- |
| 0단계 저장·권한 결정 | 완료 (이 문서) |
| 1단계 원본 보존·구조화 (로컬) | **가능.** 초안이 아니라 실제 적재까지 |
| 1단계 ERD·필드 매핑·수량 대조 보고 | 가능 |
| 2단계 검증 등급 구조·조회 계약 설계 | 가능 |
| 2단계 샘플 조회 결과 | 로컬에서만 확인. 공유 시 발췌 제외 |
| 공용 DB 적재 | **보류** |
| 서비스 RAG 색인·원문 노출 | 보류 |
| 외부 LLM API 에 원문 전달 | 보류 |
| 원본·발췌를 Git·공개 채널에 업로드 | 금지 |

요청서가 요구한 1·2단계 산출물은 이 결정 아래에서 모두 생산할 수 있습니다. 요청
범위에 공용 DB 적재와 서비스 활성화는 포함되지 않았습니다.

## 5. 아직 확정되지 않은 쟁점

**이용 목적 범위.** 개방데이터 일반 조항에 "본 AI데이터는 인공지능 학습모델의
학습용으로만 사용할 수 있습니다" 라는 문구가 있습니다. 검색 증강 생성(RAG)이나 서비스
지식 조회가 '학습용'에 해당하는지는 이 문구만으로 확정되지 않습니다. 데이터셋 71961의
개별 이용조건을 확인해야 합니다.

**문서별 이용 제한.** `Other.zip` 의 지식문서 메타데이터에 `Purpose`(연구·학습에만
사용 가능), `Cautions`(재판매, 2차 저작물 제작 등 금지) 표기가 있습니다. 문서별 조건이
일반 조항보다 좁을 수 있어 적재 시 함께 보존하고, 우선순위는 제공기관 확인이
필요합니다.

**2차 저작물 범위.** 위 `Cautions` 때문에 파생 산출물을 공용 DB에 올리는 것도 단정할 수
없습니다. 집계 통계와 코드표는 원본 재현이 불가능하므로 범위가 다르다고 보지만, 발췌를
포함한 파생물은 보류합니다.

## 6. 이 결정이 바뀌는 조건

| 조건 | 결과 |
| --- | --- |
| 수행기관·한국지능정보사회진흥원과 국외 반출 합의 체결 | 도쿄 리전 적재 가능 |
| 국내 리전 DB 확보 | 그 DB에 적재 가능. 팀 인프라 결정 필요 |
| 데이터셋 71961 개별 이용조건에서 서비스 이용 허용 확인 | 서비스 조회 검토 착수 가능 |

국내 리전 DB는 서비스 연결을 하려면 결국 필요하므로, 필요해진 뒤가 아니라 미리
논의하는 편이 낫습니다.
