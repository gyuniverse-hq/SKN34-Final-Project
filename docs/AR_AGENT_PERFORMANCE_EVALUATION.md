## 평가 방법

1. 녹음에서 시나리오 제목을 읽은 구간 5개를 제외하고, 사용자 대사 34개를 순서대로 분리했다. 각 구간을 평가셋의 턴 ID에 연결했다.
2. 시나리오마다 별도의 Redis 세션에서 정해진 화면과 착용 상태로 시작했다. 한 시나리오 안에서는 각 턴의 조작 결과와 시착 이력을 다음 턴에 이어갔다.
3. 실제 `gpt-transcribe`로 전사하고 `gpt-6-luna`가 선택한 조작을 앱에서 실행했다. 적용 전후의 앱 상태와 테스트 렌더러, 사용자에게 표시된 답변을 기록했다.
4. 평가셋의 턴별 기대값을 기준으로 호출한 동작과 필수 인자, 반환 상태, 화면 변화, 필요한 응답 내용을 확인했다. 앞 턴 때문에 기대 시작 상태가 달라진 경우도 전체 분모에 포함했다.
