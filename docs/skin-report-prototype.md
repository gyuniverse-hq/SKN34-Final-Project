# 피부 리포트: 임시 연결과 실데이터 인계

작성일: 2026-10-29. 브랜치: `feat/skin-profile-recommendations`.

사용자가 제공한 올리브영 화면은 **정보 순서와 인터랙션**의 참고 자료다. VISHUE의 아이보리·버건디·로즈
테마와 기존 Expo 구조를 유지한다. 이 문서의 임시 연결은 검증된 피부 진단·제품 효능 규칙이 아니다.

## 구현한 흐름

`분석 → 설문 → 저장 성공 → /skin-recommendations`

1. 분석 날짜, 피부 성향 요약, 리포트 정보 펼치기.
2. 먼저 살펴볼 케어 2개. 누르면 해당 항목의 상세 결과로 이동.
3. 고정 탭 **내 피부 솔루션 / 분석 결과**.
4. 솔루션: 고민별 성분 예시 → 아침·저녁·추가 케어 가로 카드 → 홈케어 노트 → 샘플 상품.
5. 상세: 항목 선택 → 모델 등급 또는 설문 답변 → 부위별 실제 숫자 표시·숨기기.
6. 상품: 샘플 미리보기 모달 또는 사용자가 요청한 실제 카탈로그 추천. 실제 상품만 상세 페이지에 연결.

최근 리포트 버튼은 이 기기의 최신 저장 결과 한 건을 안내한다. 홈·뒤로·재분석·맨 위로 버튼도 연결했다.
원본 사진을 저장하지 않으므로 사진·흐림 토글 대신 **부위별 수치 보기**를 제공한다.

## 성분 매핑 전체 목록 (검수 전)

- 건조: 히알루론산, 세라마이드, 스쿠알란
- 유분: 나이아신아마이드, 판테놀
- 민감: 판테놀, 병풀, 세라마이드
- 트러블: 병풀, 판테놀
- 모공: 나이아신아마이드, 살리실산
- 색소침착: 나이아신아마이드, 판테놀
- 주름: 아데노신, 세라마이드

위 관계는 화면 시연을 위한 연결이며 제품 효과·적합성·사용 빈도를 보장하지 않는다.
수분 모델 출력은 사용하지 않는다. 화면의 건조 관련 값은 **당김 설문**이며 수분량 측정이 아니다.

## 예시 데이터의 경계

- 저장 결과가 있으면 그 결과를 사용한다. 없을 때만 별도 예시 입력을 보여 준다.
- 저장소 읽기 실패는 오류로 표시하며 예시 결과로 숨기지 않는다.
- 예시 입력은 `skinProfileStore`, AsyncStorage, 실제 분석 기록 또는 DB에 저장하지 않는다.
- 샘플 상품은 실제 결과가 있는 경우에도 기본 시연 목록이다. 화면에 샘플임을 명시한다.
- 실제 API가 실패하거나 빈 목록을 반환하면 해당 상태를 표시한다. 샘플 성공 응답으로 자동 대체하지 않는다.
- 분석·카메라·GPU 전송·인증 로직과 원본 영상/사진 보존 정책은 변경하지 않는다.
- 서버 DB, 마이그레이션, 실데이터 시드, 외부 결제·상품 API는 이 작업에서 수정하지 않는다.

## 실데이터 인계 순서

1. 카탈로그 담당: 실제 상품 ID/카테고리/케어 태그/전성분/가격/이미지/판매 상태 제공.
2. 콘텐츠 담당: 성분 사전, 고민–성분 근거, 루틴과 팁의 검수·다국어 콘텐츠 제공.
3. 추천 담당: 피부 타입·케어 우선순위·루틴 개인화 정책 확정 및 평가셋 검증.
4. 필요하면 별도 콘텐츠 API를 만들고 샘플 상수를 교체한다. 클라이언트에서 `data/`나 서버 DB를 직접 읽지 않는다.
5. 공개 전에 샘플 기본 노출 정책을 결정하고 실제 카탈로그 기반 사용 흐름을 실기기로 검증한다.
