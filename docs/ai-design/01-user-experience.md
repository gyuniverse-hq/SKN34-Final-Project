## 1. 서비스 목표와 확정 정책

VISHUE는 **K-뷰티 중심의 자유 대화형 AI 뷰티 상담사**다. 사용자는 정해진 명령어나 질문 유형을 외우지 않고 고민을 설명하고, 상품·전성분·룩·화장법·수정화장·AR 체험을 한 대화에서 탐색한다. AR 카메라·피부 분석·사용자 제공 이미지·영상·STT·TTS·4개 언어의 사용자 경험을 목표에 포함한다.

| 정책 | 채택 원칙 |
| --- | --- |
| 자유 대화 | K-뷰티 중심. 범용 무제한 서비스가 아니라 뷰티 중심의 자유로운 의사소통 |
| 대화 주도성 | **적극적 뷰티 상담사**: 적절한 질문·다음 행동 제안, 사용자가 원하지 않는 제안 강요 금지 |
| 현재 맥락 | 현재 대화의 취향·조건·이전 상품·룩은 이어서 사용 |
| 장기 기억 | 저장에 **동의한** 취향·프로필·보유 제품만 보관·변경·삭제 가능 |
| 과거 방 조회 | **명시적 요청 B**: 현재 방 + 동의한 장기 기억을 기본 사용; 요청 시 권한 확인 후 이전 방 조회. 향후 자동 검색 C를 위한 정책 경계 보존 |
| 정보 우선순위 | 사용자 최신 명시적 의사는 **선호·목표**의 기준; 실제 상품·성분·AR 사실은 검증된 시스템 상태가 기준 |
| 자동 실행 | 상담용 조회·추천은 자율 실행; 실제 AR 변경·기억 저장·외부 행동은 사용자 의사와 권한·실제 상태를 검증 |
| 동시 요청 | **작업 성격에 따른 조정 C**: 새 의사는 즉시 반영; 취소 가능한 조회·분석은 취소·재계획, 이미 진행 중인 실제 변경은 결과 확인·복원 |
| 멀티모달 | 앱 자료 + 사용자 제공 **이미지·영상**; 기기·서버 혼합. 기존 AR 실시간 카메라 프레임 전송 금지 원칙 유지. 명시적 업로드는 별도 동의·처리 정책 |
| 신뢰성 | 일반 설명은 가능하나 상품·옵션·성분·영상 속 행동·AR 적용 성공은 근거·실행 결과 없이는 확정하지 않음 |

사용자 의사가 명확하면 불필요한 되묻기 없이 수행한다. 명시적 요청 없이 AR을 조작하거나 현재 대화의 일회성 선호를 자동으로 장기 저장하지 않는다. 특히 피부 분석의 experimental_unvalidated 결과를 의료적 진단으로 표시하지 않는다.

## 2. 14개 사용자 능력 지도

| ID | 능력 | 제공할 사용자 경험 |
| --- | --- | --- |

| C02 | 사용자 이해·개인화 | 현재 상황·예산·취향·자기보고·동의한 프로필 고려 |
| C03 | 상품 탐색·추천 | 실제 상품 후보, 검색 조건 유지·변경·이유 |
| C04 | 상품 비교·대체 | 제품·호수 비교, 보유 제품 대체 |
| C05 | 성분·피부 고민 상담 | 실제 전성분 판정과 일반 성분 지식을 구별 |
| C06 | 스타일·룩 탐색 | 분위기·사용 상황·영상 룩 검색 |
| C07 | 화장법 코칭 | 단계·기법·도구·다음/이전 안내 |

| C09 | AR 메이크업 체험 | 상품·호수 적용, 강도·부위 조절, 취소·Undo·복원·실제 ACK |

| C12 | 다국어·음성 대화 | 한국어·영어·일본어·중국어, STT·TTS, 끼어들기·재생 중단 |

C10·C11은 특정 메뉴에 한정하지 않는 공통 능력이며 C12는 전 시나리오에 교차 적용한다. 이 능력은 에이전트 개수를 의미하지 않는다.

## 4. 모든 시나리오를 교차 검토할 변형 축

1. 사용자 표현: 직접 명령 / 간접 고민 / 모호한 표현 / 비정형 발화 / 다국어 / STT 오인식.
2. 대화 과정: 이어 말하기 / 지시어 / 조건 변경 / 질문 거절 / 오류 정정 / 목표 변경 / 다른 방 참조 요청.
3. 데이터 상태: 확정된 근거 / 일부 누락 / UNKNOWN / 출처 철회 / 미승인 자료 / API 오류 / 오래된 상품·가격.
4. 실행 상태: 조회 진행 / 분석 취소 / 실제 AR 실행 중 / 중복 요청 / ACK 유실 / 복원 실패 / 앱 재시작.
5. 미디어·개인정보: 업로드 동의 / 동의 철회 / 삭제 / 원본 접근 불가 / 장기 저장 요청 / 민감 정보 미보유.
6. 사용자 환경: 무음·음성 응답·TTS 중단, 카메라 권한 거절·추적 끊김·비지원 기기.

대표 시나리오가 12개라는 이유로 모델에 12개의 의도만 허용하지 않는다. 평가에는 모르는 표현·장기 대화·다단계 과업을 별도로 포함한다.

## 5. 사용자 경험 판단 경계

- **친절한 질문 vs 반복 질문**: 이미 충분한 정보가 있으면 질문 없이 답하거나 도구 호출.
- **미디어 출처 구분**: 영상 제목·설명만 관찰한 것과 실제 프레임·음성 전사·검수 레시피를 엄격히 분리.
- **상품 호수 일치**: 실제 AR 적용 상품·호수는 서비스 카탈로그의 검증된 항목만 사용. 추정 색상을 실제 판매 호수로 가장하지 않음.
- **AR 상태**: 제안·적용 요청·실제 렌더·서버 ACK를 별개로 기록. 취소·Undo·복원은 별개 기능.
- **개인정보**: AR 실시간 카메라 프레임은 기기 내 처리. 별도 참고 미디어 업로드·피부 분석 서버 경로는 다른 동의·전달·보존 정책.
- **의학적 단정 금지**: 의료적 진단·치료 주장과 화장법/성분 설명을 구분.
- **일상 대화의 경계**: 뷰티와 무관한 일반 대화를 제품의 주목적으로 확장하지 않음.
