## 2. 해결하려는 문제

- **누가 / 언제:** K-뷰티에 관심 있는 외국인. 방한 준비·명동/올리브영 방문 전후·귀국 후 직구.
- **현재 방식:** 유튜브 시청 → 제품명 검색 → 화해/올리브영/매장 → 테스터. 앱·검색·매장이 분리.
- **영향:** 선택 시간 증가, 색상 미스매치, 셀럽 룩 제품 세트를 한 번에 못 담음.
- **근거 수준:** 가설 단계. AR 전환율·Look-to-Cart 효과는 UT로 검증.

---

## 3. 사용자와 핵심 경험

### Persona

| 유형 | 불편 | 목표 |
| --- | --- | --- |
| 방한 관광객 | 테스터·언어·큐로 시간 소모 | 미리 룩을 고르고 매장에서 빠르게 구매/수령 |
| K-팝/셀럽 팬 | 튜토리얼 제품을 일일이 찾기 어려움 | 셀럽 메이크업을 내 얼굴에 적용 후 세트 구매 |
| 해외 직구 유저 | 실물 없이 색상·텍스처 판단 | AR Try-on 후 해외 배송/결제 |

### 핵심 여정 (Discover → Try → Cart)

1. 카탈로그 또는 셀럽/유튜브 룩 선택  
2. 카메라 얼굴 인식 → AR 마스킹(립/블러셔/섀도)  
3. 스타일 매핑 + 매칭 제품 세트 표시  
4. Look-to-Cart → 온라인 결제/해외배송 또는 매장 수령 가이드  
5. 예외: 카메라 거부·인식 실패 시 스와치/참고 이미지 폴백

## 4. 기능 및 발전 가능성

### Must (핵심)

1. **E-Commerce Base** — 검색, 성분·리뷰, 장바구니, 모의결제, 매장 수령/위치 안내  
2. **AR Virtual Try-on** — 실시간 랜드마크, 색상·텍스처 렌더링  
3. **YouTube + Celeb Style** — 영상 메타 수집, 메이크업 포인트 → AR 일괄 적용  
4. **Look-to-Cart** — 룩 사용 제품 세트 일괄 담기  

### Should / Could

- 피부톤/언더톤 추천, 다국어·성분 번역, Before/After 저장, 재고·픽업 고도화  

### 장기 확장

- 브랜드/올리브영 제휴, 다른 K-Culture 룩, 추천·쇼핑 에이전트 협력

## 5. 데이터 · AI · 기술

### 필요 데이터

- 화장품 카탈로그 (색상 HEX/텍스처, 성분, 리뷰)  
- 셀럽/룩 메타 (룩 ID ↔ 제품 매핑)  
- YouTube Data API v3, Maps/매장 POI  

### AI/CV를 쓰는 이유

- **CV/AR:** 실시간 Try-on에 랜드마크 필수  
- **스타일 매핑:** 튜토리얼 포인트 → 마스크/제품 파라미터  
- **LLM/에이전트(후보):** 다국어 Q&A, 룩 설명, 추천 조율  

### AI 없이 대안

- 정적 색상 오버레이 + 수동 큐레이션 세트만 → 차별화·체험 품질 약화  

### 스택 후보 (미확정)

| 영역 | 후보 |
| --- | --- |
| App | React Native / Flutter |
| AR/CV | MediaPipe / ARKit / ARCore / DeepAR |
| Backend | FastAPI / Node / Spring Boot |
| External | YouTube API v3, 결제, Maps |

## 7. 검증 · 시연

### 가설

1. AR이 있으면 선택 시간·실패감이 줄어든다.  
2. 룩 → 세트 → Cart가 분리 검색보다 전환·만족이 높다.  
3. 매장 수령 가이드가 실용적이다.  

### 방법·지표

- UT: “셀럽 룩 찾아 장바구니 담기” — 완료율, 시간, 앱 전환 수  
- 데모: Try-on → Look → Cart (30초~2분)  
- KPI: Cart 추가율, “다시 쓰고 싶다” 비율

## 9. MVP 마일스톤

### Phase 1 — E-Commerce

제품 카탈로그·상세 → 장바구니·모의결제 → 매장 수령/위치 안내  

### Phase 2 — AR Vision

카메라·랜드마크 → 립 Try-on → 블러셔/섀도 확장 → 제품↔마스크 연동  

### Phase 3 — YouTube & Look-to-Cart

영상/룩 목록 → 큐레이션 스타일 AR 적용 → 세트 일괄 장바구니
