## 4. 확인된 이슈

**QA 가 참조하지 않는 문서가 1,878개(60%)입니다.** 고유 문서 3,108개 중 QA 가 실제로
가리키는 것은 1,230개뿐입니다. 요청서가 "동일 문서가 원문 폴더와 사용·미사용 폴더에
중복 가능" 이라고 한 그 미사용분으로 보입니다. **이 문서들은 QA 를 통한 검증 경로가
없으므로 근거 등급을 QA 연결 문서와 같게 두면 안 됩니다.**

**출처 한 자리에 파일명이 둘입니다.** `File NameN_1`(.doc 원문)과 `File NameN_2`(.json
메타)이며 9,181건 중 9,180건은 이름이 같습니다. **1건만 서로 다른 문서를 가리킵니다.**

| SEQ | 위치 | 내용 |
| --- | ---: | --- |
| `A002263_01_QA1` | 1 | `_1` 과 `_2` 가 각각 실재하는 다른 문서를 가리킴 |

연결은 `_1`(.doc)로만 했습니다. `_2` 로 연결하면 이 경우에 근거 없는 연결이 생깁니다.
`_1` 로 안 붙고 `_2` 로만 붙는 행은 0건이므로 `_2` 를 쓰지 않아 잃는 연결은 없습니다.
두 값 모두 `qa_source_link.file_name_raw` / `file_name_raw_2` 에 보존했습니다.

**연결 실패 224건(2.4%)** 은 참조한 파일명에 해당하는 `.doc` 가 `Other.zip` 에 없는
경우입니다. 임의로 비슷한 문서에 붙이지 않고 `unmatched` 로 남겼습니다.

**메타데이터가 없는 문서 124개** 는 `Purpose`/`Cautions` 도 없습니다. 문서별 이용조건을
확인할 수 없으므로 `rights_status` 를 `pending_confirmation` 에서 올리지 않습니다.

**`Other.zip` 에 `.ini` 파일 10개** 가 있습니다. 요청서의 "기타 메타 파일 등 별도" 에
해당하며 적재하지 않았습니다.

**추천·주의 성분은 쪼갤 구분자가 없습니다.** 문자열 18,062개에서 쉼표는 633번,
줄바꿈은 1번만 나오고 구분자 후보를 바꿔도 문자열당 토큰이 1.0 이었습니다. 한 문자열이
곧 한 성분이므로 1:1 로 적재했습니다. 식약처 현행 표준명과 일치하는 것은 4,560건
(25.2%) 이고 나머지는 `unknown` 입니다. 모양별로는 영문·학명만 31.4%, 한글 단일어
19.4%, 한글+공백 17.0%, 한글+괄호 6.6% 입니다.

**학습·검증 분할에 대상자 누출이 있습니다.** 검증 1,000건 중 403건(40.3%)이 학습과 같은
대상자에게서 나왔습니다. 완전히 같은 질문·답변의 교차 중복은 0건입니다. 인수인계 문서의
기존 분석(공유 339종, 403건)과 같은 값입니다. 평가에 쓰려면 대상자 ID 단위로 다시
분할해야 합니다.
